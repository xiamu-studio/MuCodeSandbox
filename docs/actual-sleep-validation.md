## 恢复条件与范围

执行自动唤醒设置需要在 macOS 系统认证窗口完成电脑管理员认证。
这不是 Apple 开发者账号，也不是新的应用签名条件。测试程序不会
读取、保存管理员密码，不修改其他唤醒事件或全局休眠参数。

入口为 `npm run test:host-sleep-actual`，提供已校验的网络组件缓存
`MU_TEST_SING_BOX_CACHE`。测试完成后运行 `npm run test:host-sleep-actual-evidence`
独立检查系统日志、实际 Electron 原生事件、旧终端 / TCP 流 / 文件
授权关闭、不自动恢复、手动重新启动和选定客体抓包。

此测试不覆盖浏览器 / Claude 实际任务、hypervisor 全程首包、切换
Wi-Fi、真实住宅线路或全天运行；即使通过也不能扩大这些结论。
