## 实现范围

- 打开请求和运行中的打开任务都在浏览器画面区域显示加载状态与日志入口。
- 浏览器页取消重复的外部打开提示，任务失败也在画面区域说明。
- 本地首页显示实际浏览器的出口 IP / 地区及自身语言 / 时区，支持网址输入。
- 首页请求公开 HTTPS IPinfo，有限回退到 ipify；失败不保留成功显示。
- 默认和旧 example.com 占位配置解析为固定本地页面，自定义网址保留。
- Chrome 首页按钮返回本地页；不添加网络端口、宿主权限或账户凭据。
- 客体文件在根所有、不可写目录内原子发布，权限为 0644。
