# 已停止的浏览器内核研究

2026-10-10 用户要求默认采用官方浏览器，删除无必要的浏览器内核改造和构建材料。

已移除自编译脚本、源码补丁及其专用测试；下载的完整源码 / 构建依赖、专用构建虚拟机和缓存按用户授权清理。当前运行时仍使用固定版本、校验下载文件的官方 Chromium，未包含任何自行修改的浏览器内核。

原研究没有编译出浏览器，也没有证明修复生效。网页后来注册字体时部分 Worker 未更新，以及主动让 GPU 进程崩溃后的原 Worker 画布空白，仍是保留的兼容性失败；不能据此认定正常网页不可用或会封号，不能把失败改成通过。

原始报告、日志和当时的源码快照保留在 `test-results/`。详细调查移入 [历史档案](archive/browser-native-patch-validation.md)，其中的命令和路径不再是当前开发指令。

后续重点是官方版本升级验证、资料保留、沙箱与网络防护、基本媒体能力及长时间运行。自定义浏览器内核不再是项目交付前置；仅在必要功能确实无法通过官方版本 / 标准配置实现，并经用户明确决定后重新讨论。
