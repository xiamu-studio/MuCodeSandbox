## 实现范围

继续使用官方 Linux ARM64 浏览器程序，不编译或修改 Chrome 内核。

不代表已验证所有稳定渠道版本或自动跟随线上最新版本。

备份路径由 root 控制；归档禁止路径逃逸、链接和设备条目。
现有安装事务负责批准程序的暂存、校验、切换和中断恢复。

候选窗口不开放给用户，先检查实际版本、页面和 Worker 的语言 / 时区 / Linux
特征、画布像素、真实 renderer / GPU 沙箱和网络规则完整性。通过后持久提交，
再打开配置页。正式提交前失败后恢复旧浏览器选择、对应策略及旧资料，关闭候选访问。
下次打开浏览器或显式恢复会处理未提交事务；已提交事务只完成清理。

浏览器启动偏好使用官方“新标签页”配置，由管理器在防护核验后选择启动页，
避免上游自动恢复旧标签页而在核验前访问原网站。这不清除 Cookie 或网站数据。

## 安装包退出修复

首次实际包内 VM 验收因隐藏窗口截图等待稳定状态超时而失败，保留失败记录。
清理阶段进一步发现：浏览器画面连接未断开时，服务先等待 HTTP 服务关闭，
但画面连接要等后续浏览器关闭才能释放，导致应用退出互相等待。

现改为停止接受新连接后关闭受管浏览器，再等待 HTTP 服务关闭完成。
新增回归测试使用真实 WebSocket 连接，并暂停客户端读取来模拟不回应关闭
握手的画面，验证服务退出、会话撤销及重复关闭。完整 115 项测试通过。
