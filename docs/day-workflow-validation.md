## 覆盖范围

- 实际浏览器一次合成登录，Cookie、localStorage、IndexedDB 和语言 / 时区检查。
- 浏览器持续接收本地流，每五秒回报收到的计数；连接重建或超过 15 秒的回报空窗会使独立验收失败。
- 同一个原生终端每五分钟运行官方 Claude Code 的独立文本请求。本地模拟模型，不登录、不调用付费模型；不是单个 CLI 进程运行全天。
- 定期检查同一开机 ID、浏览器服务主进程、防护完整性、宿主网络监测、浏览器进程沙箱、画面像素和磁盘余量。
- 每轮验证普通用户不能提权，以及绑定物理网卡的直连请求失败。
- 每 30 分钟导出一份物理出口抓包，单份上限 64 MiB；记录轮换空窗，不能称为无间隙抓包。
- 原始回报、CLI 输出、PNG、抓包、源码快照和包内模块散列保存到独立目录。结束后删除本轮专用虚拟机和数据，保留验收证据。

## 运行

提供已缓存、经散列验证的 sing-box 压缩包路径：

```sh
MU_TEST_SING_BOX_CACHE=/absolute/path/sing-box-1.14.3-linux-arm64.tar.gz \
  npm run test:day-workflow -- --duration 120 --interval 30 --chunk 60
```

完整后台任务使用默认 24 小时 / 五分钟观察 / 半小时抓包分段：

```sh
MU_TEST_SING_BOX_CACHE=/absolute/path/sing-box-1.14.3-linux-arm64.tar.gz \
  npm run test:day-workflow -- --launch
```

启动返回 PID 和独立证据目录。必须检查该 PID 的真实进程 / 命令及
`report.json` 进展；单独存在 `job.json` 不证明任务仍运行。
电脑休眠、程序关闭或测试故障均不能被计为成功的运行时长。

任务结束后，对准确目录独立复核：

```sh
npm run test:day-workflow-evidence -- /absolute/path/day-workflow-TIMESTAMP/report.json
```

`evidence.json` 仅在实际完成 86,400,000 毫秒要求时标记
`twentyFourHoursVerified: true`；短测通过只证明短测范围。
