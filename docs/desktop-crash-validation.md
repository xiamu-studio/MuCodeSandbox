## 9378141 失败记录

PTY 终端和宿主文件授权后，强退应用主进程。代理入口与流连接在
该轮 51 ms 后观察为关闭，终端断开、文件授权不可用，后续新请求
持续失败；VM 保持运行，45,075 ms 后内核联网许可确认为到期。
两份物理抓包未批准外发 0，已有业务阻断正常。

但 45 秒后仍存活一个由应用创建的 SSH 子进程，脚本按清理失败
返回失败，不将本项算作完整通过。该进程对应旧宿主桥接的 `ssh -N`
通道，宿主 HTTP 授权服务已随应用结束，文件读取失败；不能把遗留
进程描述为成功读取文件或已经发生直连泄漏。

失败报告 `desktop-crash-probe-failure.json` 与原始目录
`desktop-crash-1791672515336/` 保存冻结包身份、子进程、许可观察、
抓包与当轮脚本快照。测试脚本随后关闭自有残留进程并删除测试 VM /
基础镜像 / 数据，核心运行 VM 未改动。

就绪，才发布可用文件授权。应用强退关闭 stdin 管道后，客体使用
pidfd 关闭对应 SSH 会话；不依赖宿主授权服务继续响应，也不增加
任意命令授权。正常撤销和出错清理仍使用原有路径。
