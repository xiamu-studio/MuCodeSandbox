# 0.4.11 安装状态误显示修正

日期：2026-10-12（台北）。本机应用已更新，build `054724502559b855`，CDHash `b6cab2b26f2248d3157764f01dcf13c912638f71`。

原因：两个客户端在前序真实 VM 测试已确认安装。环境因不足两个独立出口回执被保护停机后，安装状态接口无法读取停止客体，返回空列表；原界面把空列表、首次检测与查询失败当成“未安装”。停机本身不卸载客户端或清除资料，本轮没有重装、重置或删除环境。

修正：停止 / 未创建环境显示“启动后检测”，运行中的首次查询显示“正在检测”，查询失败显示“检测失败”。只有当前环境、当前运行状态的明确缺包结果显示“未安装”，未知状态没有可用安装按钮。结果绑定环境 ID 和运行状态；切换环境不沿用旧安装数据。桌面页直接显示保护停机原因。

已验：类型与生产构建；隔离 UI 的停止、失败、恢复、确认缺包、环境切换及 1320 / 800 / 390px 布局；应用包依赖、临时签名、封装和篡改拒绝；本机0.4.11真实窗口的停止状态。原始材料：`test-results/desktop-installation-state/ui.json`、`package.json`、`native.json`。夹具只使用临时数据目录，关闭其虚构 VM 的后台保护定时器以稳定测试，不改本机真实保护。

仍未解决：本次重新启动真实环境仍因不足两个独立出口回执失败，环境保持关闭。此报告不声明线路已恢复、全天稳定或当前已取得运行中客体安装状态；没有降低回执门槛或关闭出口锁定。旧0.4.10客户端启动 / 清理与261项测试按原版本范围保留，本次没有重跑这些不相关长测试。
