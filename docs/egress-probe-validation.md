## 修复

只在配置出口锁定时增加专用回环 SOCKS 入口，限制为 mu-probe UID。
普通开发程序不能访问此入口，也不能访问 mu-net 的私有 SSH 代理
入口。先装内核规则，再开放监听。检测使用同一个 sing-box 上游、
TLS 校验和指定 DoH；不使用 Mac 直连测量，也不临时激活业务许可。
检测入口的 UDP 先拒绝，再处理其他 DNS / 路由规则。
