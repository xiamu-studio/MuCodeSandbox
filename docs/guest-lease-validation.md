# 应用故障后的客体自动断网

日期：2026-10-10。防护版本 5，适用严格 Linux VM。

## 实现

业务网络使用内核 nftables 超时集合，每次许可有效 45 秒。管理器每 8 秒检查防火墙、开机配置、路由、DNS，以及启用时的出口 IP；检查通过才续期。许可过期、撤销或开机未批准时，输入和输出都拒绝业务流量，包括已有连接。正常退出主动撤销；管理进程崩溃无需客体监控进程参与，内核许可自行过期。

开机网络依赖先装载空许可表。root 专用助手绑定随机管理会话与客体 boot ID，串行执行操作；过期或已撤销会话不能重新激活。宿主核对策略结构、开机文件与助手指纹，动态许可内容不计入结构指纹，但有效状态独立检查。开发用户不能续期或切换到检测身份。

管理 SSH、DHCP、普通回环与专用检测身份有明确例外。共享本地 DNS 请求须业务许可，专用检测经配置的 DoH、固定解析地址和验证 TLS 直接发起。透明转发固定使用 sing-box 1.14.3 内置 gVisor 栈；外联目的地址仍受原有默认拒绝规则约束。

## 历史失败记录

首轮关键断网行为通过但抓包导出因 root 目录权限失败，保留 `guest-lease-before-capture-export-fix.json`。改为仅给管理账户导出私有测试包，不修改生产目录权限。

`guest-lease-public-doh-timeout.json` 和 `guest-lease-before-gvisor-fix.json` 保留业务关闭时检测超时；抓包确认默认 system 栈改写内部 TCP 连接，检测标记丢失，回复被许可表拒绝。显式使用组件内置 gVisor 栈后，生产 TLS / DoH 查询与业务断网检查通过。

`guest-lease-before-capture-spacing-fix.json` 保留物理接口解析错误。抓包实际有数据，但接口字段间有两个空格；改为解析字段，并要求正向包和目的地址检查。所有旧失败均不作为完整通过证据。

## 边界

这不是退出瞬间断网：硬退出后至上次许可的 45 秒截止之间，已有批准业务仍可联网。许可目录 ENOSPC 和一次同地址 DHCP 续租已有独立测试；休眠期间客体时钟和内核超时如何推进、唤醒瞬间、Wi-Fi 切换、长期续租 / 地址变化和整盘写满仍需独立测试。

检测账户与透明服务保留必要外联能力；客户端业务不能使用这些身份，root 仍能修改客体规则。该防护不覆盖其他 Mac 程序，也不证明每个目的网站看到固定公网 IP。商业线路、正式 Network Extension、macOS VM 和 Claude Desktop 的差距仍保留。

实现参考：[nftables 超时集合](https://netfilter.org/projects/nftables/manpage.html)、[sing-box TUN 栈](https://sing-box.sagernet.org/configuration/inbound/tun/#stack)、[curl DoH 与固定引导地址](https://curl.se/docs/manpage.html#--doh-url)。本项目固定组件版本，后续升级仍需重复上述实际验证。
