# 支持范围与限制

## 当前测试版

- Apple Silicon Mac，构建目标为macOS 13及以上；Intel Mac与Windows不在当前支持范围。
- 当前为本地临时签名测试包，没有Developer ID正式签名和Apple公证。另一台Mac可能提示无法验证开发者；正式分发需要完成对应签名与公证。
- 未对每一种Mac型号、macOS版本、外接屏幕及长期休眠/网络故障组合完成验收。构建目标不等于所有旧系统已实机验证。
- 首次使用需要联网安装运行组件和Linux镜像；完整离线部署不在当前包内。
- 浮窗可在应用内移动和缩放，不能独立拖到另一块屏幕。
- 不保证第三方账号可用、平台不关联账号或识别为物理家用电脑。不同IP与虚拟机隔离无法提供这类承诺。

## 后续工作

正式签名、公证和可验证的更新流程；第二台Mac首次安装及旧系统验证；更多设备和网络故障组合的长期检查。新增平台或图形后端需要独立适配和防护验收。

遇到问题时可提供应用版本、机型、macOS版本和脱敏诊断。不要在公开反馈中粘贴密码、Key、登录令牌或含私人内容的完整备份。
