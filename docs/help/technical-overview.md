# MuCodeSandbox 技术说明

Mac应用负责界面、环境管理和画面传输；受管浏览器、桌面客户端和命令行任务在独立Linux虚拟机中运行。当前构建使用Electron、Lima和Apple虚拟化框架，支持Apple Silicon。

## 资料边界

每个Linux环境有自己的磁盘和应用资料目录。只有明确授权的项目目录才与Mac共享；共享目录允许写入时，原文件也会被修改。同一VM中的程序属于同一Linux用户，不代表这些程序彼此强隔离。

宿主命令与目录授权分别控制。虚拟机外的Mac程序、云端电脑和第三方云服务不属于该Linux环境的网络防护范围。

## 网络边界

严格透明模式使用Linux防火墙、受控DNS、配置的代理或隧道及内核联网许可。出口核验、规则或保护连接异常时，撤销访问并停止环境，不自动切换直连。

宿主按环境分别管理通道与状态。出口检测是定期测量，不能当成每一个目标连接都已确认出口相同的证明；也不能保证网站不关联账号或不触发风控。取得客体root或宿主用户权限的恶意程序不属于绝对隔离保证。

## 显示与输入

查看器传输Linux画面，保留认证连接和解码状态。隐藏功能页暂停接收更新，返回时恢复；重绘请求不会重新加载网站。当前使用已验证的软件绘图路径，没有承诺硬件GPU直通。

文件和剪贴板通过显式操作传输。文字、图片和文件有独立的类型、大小及目标检查；不自动同步整个Mac剪贴板。翻译由手动操作触发并使用当前沙箱网络。

## 本机数据

环境配置、凭据、日志和VM磁盘保存在当前Mac用户的数据目录；安装包不包含这些运行数据。凭据加密降低配置文件明文泄漏风险，不能抵御同一Mac用户权限下的恶意程序。更换Mac后需要自行配置，或者明确导入自己的加密备份。
