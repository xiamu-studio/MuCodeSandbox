# MuCodeSandbox 使用指南

## 首次安装

当前测试包支持 Apple Silicon Mac，构建目标为 macOS 13及以上。新设备和旧系统仍需实际验证。首次使用需要联网下载运行组件和Linux镜像，磁盘还要为环境、文件和备份预留空间。

1. 将应用拖到“应用程序”，再从该目录打开。
2. 在“系统设置”安装Lima运行组件，等候已就绪。
3. 新建Linux沙箱，按实际情况选择CPU、内存、磁盘、语言和时区。
4. 填写自己的代理或隧道配置。需要强制出口时启用仅代理联网、透明代理，并填写自己确认的固定出口IP。
5. 启动后等候防护核验，再查看网络状态和实际出口。先用本地首页确认画面和文件工具，再自行登录所需服务。

应用安装包不提供VPS、代理账号、翻译Key或预先登录的环境。配置只在当前Mac的数据目录中保存。

## 日常工作

浏览器、桌面应用和终端在所选Linux环境中运行；切换功能页保留已建立的连接。停止环境会关闭其中的程序，正常关闭不会清空已保存资料。

画面工具栏提供文件与粘贴、中文输入、显示设置和全屏。偶发显示缺失可在“显示设置”中点“重绘画面”，保持网页和连接。标题旁显示沙箱配置时区的日期、中英文星期和时间，悬停可查看完整信息。

## 文件与剪贴板

- 文件传输：拖入Mac文件或选择上传，每个文件最多150 MiB，显示传入进度，保存确认后才算完成。新文件默认保存在沙箱下载目录。
- 下载到Mac：在沙箱下载或导出目录中保存文件，再从文件面板刷新、选择并下载。文件名、修改时间和目录有助于确认内容。
- 项目目录：仅共享明确选中的专用文件夹，默认只读。允许修改后，沙箱对该目录的修改会影响Mac原文件。
- 图片：复制Mac图片后，在文件面板手动粘贴到沙箱剪贴板；目标应用支持图片粘贴时可自行使用。不会自动同步整个Mac剪贴板。
- 文字：可手动发送到沙箱或取回已复制的沙箱文字，最多64 KiB。终端多行粘贴需要支持安全粘贴，不自动按回车执行。

文件只在当前VM中保存；重建或删除环境会清除VM内文件。Mac共享源文件和你另存的备份需要单独管理。

## 中文输入与翻译

先选择沙箱中的目标输入框，再打开中文输入小窗。粘贴原文或译文只执行粘贴，不自动发送。

可拖动标题移动小窗，拖动右下角调整大小；点外部收起并保留草稿。放大阅读同样支持移动和缩放，浮窗限于当前应用窗口。退出或重开应用前，请自行保存未发送草稿。

翻译需要你主动配置自己的DeepSeek API Key，并且只有点击翻译才发送原文。每次最多16,000字；取回并翻译默认英译中，也可手选方向。清空或删空原文后恢复自动互译；纯数字或符号需手选方向。译文保留换行和列表，但模型可能改变内容或格式，使用前应核对。

Key加密保存在当前Mac，不回显，不随环境备份导出。不会自动重试，也不会在沙箱网络失败后改用Mac直连。

## 联网保护

“已配置”与“已通过核验”不同。请看当前防护、联网许可和实际出口检测状态；虚拟机运行中不等于已经确认安全可用。

出现超时或回执不足，表示未确认到足够检测结果，不等于已证明IP变化。恢复线路后使用正常核验流程。IP确实变化时，需要先核对线路或由你明确修改批准值。系统不自动接受新IP，不在代理失败时改成直连。

休眠、网络变化、应用退出或保护连接异常可能触发断网停机。故障原因和原始记录保留在日志中；重新核验成功后才恢复访问。出口检测只覆盖所检测目标，不证明所有网站看到的出口完全相同。

## 快照、备份与清理

停止环境后可创建快照或导出加密备份。备份包含VM资料，不包含Mac共享源文件，也不自动携带翻译Key。导入旧备份可能带回旧登录状态。

重置浏览器资料只清浏览器；彻底重建或删除环境会清除该VM的磁盘与本应用管理副本。操作前先保存需要的文件。普通关闭、重开或功能页切换会保留已保存资料。
