# Windows 支持范围

## 当前预览版

已提供独立 Hyper-V Linux 环境、受控代理与批准出口核验、异常关闭访问、浏览器画面、终端、手动文件传输、文字与图片剪贴板，以及中文输入与翻译工具。

已提供组件准备、磁盘扩容、资源保护、故障恢复向导、加密备份与恢复及安装升级保护。具体是否就绪，以本机组件状态和当前操作结果为准。
