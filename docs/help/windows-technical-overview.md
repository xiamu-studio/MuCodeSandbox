# Windows 技术方案

未发布快照副本的清理依赖创建时保存的受保护原对象身份。核验和确认是独立任务；删除逐项固定句柄并重新核对 VM/检查点/宿主引用，保留原计划供中断接续。旧的无凭据文件继续保留。普通文件和无头页面验证不代表完成管理员与真实 Hyper-V 验收。

## 运行边界

Windows 桌面应用通过本机会话访问本地服务。受保护的权限代理执行 Hyper-V 与磁盘操作；环境使用独立 Linux 虚拟机。Windows 原生窗口、文件选择、输入法与快捷键遵循 Windows 习惯。

## 网络边界

Linux 透明代理与防火墙控制业务流量。启动时验证批准出口与防护摘要，联网许可定期核验和续期。访问会话撤销后，浏览器、终端与文件传输不可继续使用旧会话。

宿主网络变化、资源压力或休眠恢复会触发关闭访问。无法确认虚拟机停止时保留错误与恢复记录，界面不会将其显示为已完成。

正常退出先关闭原生写入与客体连接入口，取消已有任务，并核验当前受保护登记中的全部环境；首次回执和最终确认必须属于同一原生会话。接受退出请求不等于完成停机，任一写入或环境未确认时保留退出错误供重试。工作进程丢失后的最后关闭只对登记中的固定环境执行停止核验，不采用返回的磁盘或登记信息；与资源、电源保护共用最多4个核验任务。真实权限及Hyper-V停机行为仍需实机验收。

## 读数与显示

CPU、内存、磁盘和运行时间来自 Linux 的实际只读观察；浏览器版本来自客体已安装程序。配置值与实测值独立展示，失败与过期读数不会替换为宿主数据。

组件与资料版本通过同一次受防护会话约束的只读观察返回。资料检查以 dev 用户逐级固定目录及 no-follow 句柄，只读取最多256字节的 Last Version，复核身份、权限及读前后状态，不读取其他资料。较新或无法信任的记录会在创建显示服务前拒绝；准备偏好设置前及最终启动器内再次复核。缺失记录单列为未知并保留既有启动语义，不把它当作兼容证明。在线更新、资料检查点及完整版本回滚仍待交付。

浏览器画面、文字、图片、音频与文件通过当前受保护会话传输。文件交换有大小、并发、路径和会话边界；当前不向客体持续挂载宿主项目目录。

## 存储与恢复

环境元数据、加密凭据、受保护磁盘和备份操作分别校验归属。加密备份恢复会检查完整性、可用空间及目标冲突。恢复后的环境保持停止，启动时重新建立网络防护会话。

快照的事务恢复仍在开发，当前版本未开放快照操作。代码测试与合成界面验收不等于真实硬件兼容、签名或正式发行验收。

运行中清理旧快照已采用独立任务和依赖核验，保持当前防护会话及独立停机通路；恢复与创建继续要求停机。该入口尚需真实 Hyper-V 和安装版验收，当前保持关闭。

历史快照导出的原生读取、加密档案、任务及确认页面已接线，入口仍默认关闭。读取固定在所选快照的磁盘、种子和当时配置，不替换为当前盘或当前连接身份；运行环境的访问与停止保持独立。普通进程的IPC、归档和合成页面检查不能代替受保护权限、真实Hyper-V及安装版导入启动验收。

资源或电源异常后的关闭核验按环境独立执行，保护任务最多同时核验4个环境，尚未尝试的环境优先于失败重试。某个环境忙碌或关闭未确认时，其他环境继续关闭；全部当前环境核验完成前，不显示全部停止。该行为仍需真实硬件与安装版验收。


Claude Code 的 Windows Linux 管理链路使用固定批准的 x64 原生组件，无需 Node.js。宿主仅缓存固定摘要的公开发行包，客体独立核验归档与逐文件摘要，不执行软件包脚本；独占发布不覆盖已有版本，兼容的中断文件可继续，未知或变化内容保留并拒绝。状态检测只读取组件资料，不运行 CLI、不访问账号或发送内容；专用终端仅在用户选择后以 dev 用户启动，仍受当前防护会话与一次性票据约束。运行入口默认关闭，真实 Linux、组件执行与安装版交互尚待验收。


网络观察使用与终端、文件访问相同的任务准入：历史快照导出、运行中删除旧副本及编程组件安装保持采集；其他忙碌操作仍拒绝。每次客体读取前后均核对原防护会话、线路和当前许可，失效或跨会话的迟到数据不交付。观察接口附带原环境生命周期状态，暂停检测不能作为已确认停止的证据；历史IP、核验时间和缺失回执继续按原记录展示。
