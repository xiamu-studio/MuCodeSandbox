# Windows 使用指南

## 准备与创建

在系统设置检查 Windows 虚拟化、Hyper-V 和 OpenSSH。按组件准备页的实际提示操作；需要 Windows 管理员确认时由你亲自处理。软件不会自动重启电脑。

新建 Linux 沙箱，填写名称、备注、资源、时区、语言以及代理。当前受保护基盘至少需要 32 GiB 虚拟磁盘、2 GiB 内存。虚拟容量不会立即全部占用宿主磁盘，但创建与扩容会检查增长预留。

## 线路与防护

本机 Clash 填写 127.0.0.1 和实际监听端口；远程代理填写提供商地址、端口及所需凭据。HTTP、HTTPS 和 SOCKS5 均通过受控 Linux 线路运行。HTTPS 代理还需要正确的证书服务器名称。

填写你批准的出口 IPv4。保存配置后，环境保持停止；启动时必须取得两处独立且一致的出口回执，并核对防护规则和限时联网许可。出口变化、规则变化、宿主网络变化或休眠恢复时，应用会撤销访问并尝试停止环境。以页面记录的停机结果为准，未确认的停机需要处理。

运行中不能修改线路。总览将配置、实际读数和检测时间分开显示。线路延迟仅在你点击检测时，通过客体线路测量；读取失败不会使用 Windows 直连数据代替。

如果启动时提示出口核验或安全连接失败，先确认本机代理正在运行、监听端口与应用中填写的一致，再查看环境“日志”里的断网保护记录和技术详情。安全连接系统错误的原因可能不止一种，不能仅凭提示认定证书或出口 IP 有问题。线路恢复后，可按页面提示重新核验并启动；通常不需要删除环境。若提示宿主网络变化或休眠恢复，先退出并重新打开应用，再启动环境。停机尚未确认时，先按页面提示处理，不要反复启动。

如果确实更换了代理出口，先确认新的出口 IP，再在环境停止后到网络页修改批准值；未确认前不要关闭证书验证或出口锁定。持续失败时可保存保护记录中的诊断，以便排查。

## 浏览器、中文与剪贴板

启动环境后打开浏览器。浏览器在 Linux 中运行，Windows 显示其画面。先点击客体目标输入框，再使用文字工具粘贴；Ctrl+Enter 是下方输入区的粘贴快捷键，输入法候选选字期间不会触发。

图片可通过图片剪贴板工具传入或取回。取回的图片先显示预览，再由你点击复制到 Windows。选择文件和保存备份时使用 Windows 原生对话框。

中文输入与翻译浮窗提供原文、译文、放大阅读和字号调整。首次使用翻译时，在“系统设置”中展开“翻译设置”，自行填写 DeepSeek API Key 并保存；不要把 Key 发到聊天中。启动环境并通过联网核验后，在浏览器的中文输入与翻译浮窗输入文字、选择方向，再主动点击翻译。翻译使用你的 API 额度，请求经过当前沙箱网络；保存设置不会自动测试服务。页面显示的功能不代表所有外部服务已完成实测。

## 文件与终端

文件传输页提供下载、传入和导出目录。可以上传、下载、进入子文件夹和新建文件夹。单个文件最大 150 MiB。打开沙箱文件夹需要先打开浏览器画面。

Windows 当前通过手动传输交换文件，尚未持续共享宿主目录。沙箱中的文件不会自动出现在 Windows 项目文件夹；重要输出请主动下载保存。

终端在当前 Linux 环境中运行。快捷文字工具沿用 Windows Ctrl 操作。停止环境或防护会话失效时，终端连接会关闭。

## 虚拟磁盘空间

虚拟磁盘会随环境内数据增加而增长。删除环境内不需要的文件后，先停止环境，再在环境设置中选择“回收磁盘空间”，核对提示并输入环境名称。回收会整理已删除文件占用的空间，结束后环境保持停止；实际释放的空间可能不同，容量上限不会缩小。此功能仍为预览，请先备份重要数据。

同一窗口可以开启“定期回收”。开启后每周检查一次，仅在应用打开、环境停止且没有其他维护任务时执行；应用关闭时不会运行。若界面提示上次维护结果未确认，请保留磁盘并按提示处理，不要重复启动回收。

系统存储页的“定期清理缓存”是另一项功能，只处理确认不再使用的缓存，不回收环境磁盘或删除备份。

## 加密备份与恢复

停止环境并等待操作完成后，在环境设置中保存加密备份。选择 Windows 保存路径，设置并确认密码，核对环境名称后导出。请保留文件和密码。

在工作区选择导入备份，选择文件并输入密码，先检查备份内容和资源需求，再确认恢复。恢复拒绝覆盖已有环境。恢复完成后保持停止，由你决定何时启动并重新核验线路。

备份密码丢失后无法读取加密备份。预览版的重要文件应另保留独立副本，并确认副本可用。

## 故障处理

浏览器设置中的版本检测分别显示组件版本和资料版本。资料来自更高版本时，当前批准版不能降级打开；请保留原环境，使用匹配版本的应用或新建空白环境。恢复当前批准版组件不会降低资料版本，也不会清空资料。路径、权限或版本记录异常时，浏览器保持关闭。

缺少资料版本记录会显示无法确认此前版本，不能当作兼容证明；现有版本仍沿用缺少记录时的启动规则，打开前再次检查。这里没有在线更新，也不自动重置或回滚浏览器资料。

当前版本尚未开放快照操作。运行中清理旧快照的预览正在验收；创建或恢复快照仍需停止环境。中断后的删除应从原“待清理快照”记录继续，勿手动删除未知目录。

先看顶部错误、断网保护记录和操作记录，再进入系统设置检查资源、组件和恢复入口。不要连续重复同一个未确认完成的恢复操作。

删除环境需要输入完整名称，会永久删除该环境磁盘和管理密钥。已保存的独立备份仍由你管理。


### 后台任务期间查看日志

历史快照导出、删除旧快照或安装编程组件时，可以继续查看当前环境的出口IP及连接记录。采集仍受当前网络防护限制，停止、线路变化或会话失效后不会把迟到结果写入新的会话。

日志暂停检测时，请同时查看环境状态：等待停机确认、环境出错和已停止是不同结果。旧版本回执缺少状态时显示暂不可检测，不据此推断已停机；保留的IP仍使用原检测时间，缺失的历史出口回执不会用当前IP补齐。

### 快照提示未发布副本

复制中断后，快照页可能显示“发现未发布快照副本”。这些文件可能仍占用空间；创建和恢复新快照会暂时停用，避免反复复制。已有快照及已确认的删除记录仍可查看。界面最多列出 32 个条目，超过时会提示。

先保留这些文件并核验归属和清理凭据，不要仅按名称删除。该提示自身不代表环境损坏，也不表示存在待回滚的恢复事务；若有独立的恢复告警，仍按恢复状态处理。

支持清理的版本会显示“核验清理”。先停止环境并等待核验任务完成，再核对选定条目及剩余文件长度，输入完整环境名称确认。核验过期后需要重新核验；输入法正在组词时，Enter 不会提交清理。

清理中断后可从原记录接续，新快照功能关闭时已有清理记录仍可接续。缺少原始凭据、文件被替换或新增未知内容时会拒绝清理，原文件保留。已发布快照、当前环境磁盘和恢复回滚记录不属于此入口。功能尚未开放时，以页面提示为准。
