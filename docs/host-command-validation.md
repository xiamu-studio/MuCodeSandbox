# 本机有限命令授权

日期：2026-10-10。当前实现于源码、本机预览及 `boot-capture-candidate`
实际 Electron 包（b0cd06d）；包内命令专项于 14:16 UTC 通过独立复核。
现有目录文件操作保留；命令权限必须独立勾选，默认关闭。初始目录提供：

| 能力 | 固定执行内容 |
| --- | --- |
| Git 状态 | 工作区状态，不访问子模块 |
| Git 文件差异 | 工作区差异，禁用外部 diff、textconv、分页和颜色 |
| Git 最近提交 | 最近 20 条提交的短编号和标题，不验证签名 |

客体通过 `mu-host GRANT_ID command git-status` 等固定 ID 调用。返回 JSON
包含真实 `exitCode` 和有界 `output`；调用方应检查退出码。接口不接受追加参数、
shell、程序路径、环境变量或工作目录。文件读写权限不会自动批准命令。

## 边界

原生桥接保留授权目录描述符，使用该目录作为工作目录。执行前进行有界检查，
拒绝硬链接的普通文件，目录条目最多 20,000、深度最多 32；超限直接拒绝。
要求 `.git` 为实际目录，不能以指向其他位置的文件或符号链接代替。
系统 Git 当前固定为 Xcode Command Line Tools 中 root 所有、不可由普通用户
修改的程序；工具或进程限制文件不可用时拒绝执行。

子进程采用 macOS `sandbox-exec` 的默认拒绝策略，只读授权目录与必要系统
运行库；不允许联网、项目写入、执行其他程序或访问目录外文件内容。系统
文件元数据查询允许，以满足程序加载需要，这不是隐藏所有宿主元数据。
使用最小环境，禁用全局 / 系统 Git 配置、可选写锁、hooks、fsmonitor、外部
差异和文本转换。项目内配置仍视为不可信，不能用这些配置覆盖系统限制。

每个授权同时只运行一项命令，8 秒超时、合并输出上限 64 KiB。桥接组件与
命令属于专用进程组；撤销、到期、环境停止 / 隔离、超时或超限终止整个组。
命令失败的清理与重复关闭共用同一关闭过程，避免尚在清理就提前返回。
审计保存授权、命令 ID 和完成 / 拒绝信息，不保存命令输出或文件内容。

这只约束从此能力接口启动的命令及其子进程，不约束其他 Mac 应用，不是
Network Extension，也不证明原本失败的 Mac Chrome 进程方案现在可用。
同一宿主用户能够主动修改应用、项目和系统设置，不属于抵抗 root / 宿主
用户入侵的边界。大型项目、硬链接仓库、子模块、worktree 与任意构建命令
未包含在当前兼容范围；不应通过关闭限制来宣称兼容通过。
