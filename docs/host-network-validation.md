## 行为

读取 Mac 系统网络状态，检测出口 / 主地址 / IPv6 / DNS / 系统代理 /
主链路及 Wi-Fi 标识变化。虚拟网卡的普通地址变化和 Wi-Fi 信号强度
变化不触发隔离。组件只发送摘要、类型与连续序号，不发送明文网络
参数。组件不足 100 KiB，不需要 Apple 开发者账号、管理员权限或
Network Extension；它是监测组件，不是 Mac 全机网络过滤器。

网络变化收到后同步关闭受保护 Linux 沙箱访问，再异步撤销浏览器、
终端与宿主授权，并停机。变化之前的启动请求不能在异步检查结束后
继续执行；完成后由用户手动启动并重新核验。心跳每两秒一次，超过
15 秒没有有效消息、消息格式 / 顺序异常或组件退出均失败关闭。
失效后需重新打开应用，再手动启动沙箱，不自动恢复旧会话。长时间
宿主休眠也可能触发心跳失效，因此不能宣称休眠后只需直接启动。

## 尚未证明

没有实际切换 Mac Wi-Fi / VPN / 物理网卡，没有实际 Mac 休眠，也
没有瞬时阻断或首包时序证据。真实系统变化是否正确通知、通知合并
可能丢失的短暂变化及持续一天的行为仍需验收。网络摘要覆盖可观察
状态，不保证发现所有物理网络变化或公网代理运营商在远端换 IP；
需要固定公网出口时仍要配置并核验出口 IP 锁定。

本节监测故障 VM 专项使用终端 shell，没有运行官方 Claude Code 工具
任务；另一个全新 VM 的完整 CLI / 备份使用流程已通过。两轮均没有
真实账号、付费模型、公共 DNS 或住宅线路。同包共享目录 / WireGuard
另有通过记录；容量专项仍需补验。Mac 其他应用
不属于此监测与客体防火墙的强制防护范围。
