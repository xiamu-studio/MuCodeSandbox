# 输入草稿与译文快捷键修复（0.4.34）

## 问题与行为

“文件与粘贴 → 文字复制粘贴”在发送请求结束后直接清空文本框。请求中继续输入下一段，下一段也被清空；延迟合成接口已复现。现在只清空与已发送内容一致的草稿，新输入保留，提交给沙箱的仍是点击时的原文。

译文文本框原来没有绑定输入法保护或快捷粘贴。现在原文 / 译文共用选字状态保护：⌘Enter / Ctrl+Enter 粘贴当前框内容并收起，输入法组合中不触发；Escape 在组合中不关闭。粘贴不自动回车发送。
