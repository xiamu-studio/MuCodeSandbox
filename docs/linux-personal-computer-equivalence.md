## 可承诺的目标

构建真实、受维护、配置一致的 Linux 浏览环境；按明确检查项比较页面、
Worker、iframe、请求信息和网络路径。对照真实 Linux 电脑记录差异与
已知限制。不能承诺与物理机完全相同、任意观察者无法识别虚拟化，
也不能把配置一致、网络防护或检测网站通过当作服务方不会封号的证明。

Linux 虚拟机运行真实 Linux 内核和应用，通过虚拟设备获得硬件资源。
具备系统访问权限的程序可以检查虚拟化信息；普通网页只能利用浏览器
开放的接口和网络请求。两种观察能力需要分别说明，不能混同。

## 后续检查与工作（本轮记录，未实施）

用户进一步澄清：命令行客户端优先检查直接的系统虚拟化识别，浏览器字体
比较不是此阶段重点。命令行客户端是本地程序，其读取能力不限于终端
文字或调用 shell 命令；也可能通过运行库直接读取系统 / 设备信息。

检查顺序调整为：

1. 系统层直接识别：虚拟化报告、硬件 / 固件标记、虚拟设备、内核和架构。
   已观测到 `apple`，其余仅列为检查范围，不能声称全部查完。
2. 当前 CLI 实际行为：五轮版本绑定的限定检查已完成，更多路径仍未测。
   分开记录静态、实际读取、本地接收回执与真实账号行为，不把“技术上
   能读取”或合成接收端结果描述成真实服务端已经采集。
3. 按官方支持的配置减少非必要数据收集；不修改官方客户端、不伪造检测
   结果。关闭可选遥测不代表必要服务请求不携带任何环境信息。
4. 浏览器特征另做独立检查，不让字体等网页细项阻塞命令行范围的核对。

隐藏一个命令或改一个设备名称只能影响特定检查，不能证明所有接口都
没有虚拟化特征。系统可见性、客户端实际收集和服务方账户判断分开记录。
本轮未修改 VM、客户端或网络配置。

官方提供 [开发容器运行方式](https://code.claude.com/docs/en/devcontainer)，
并在 [数据使用说明](https://code.claude.com/docs/en/data-usage) 中说明
官方云端会话默认使用受管理虚拟机，以及可选遥测控制。这些资料说明
虚拟环境并非天然等于异常使用，但不证明任意环境或账户一定获准。

| 范围 | 工作 | 可验证的结果 |
| --- | --- | --- |
| 正常浏览器渠道 | 选择受维护的 Linux ARM64 稳定发行版，保持真实版本和升级机制，复用现成包 | 来源、架构、版本、资料保留及网络保护核对，不编译内核 |
| 标准桌面配置 | 对照真实 Linux 的字体、区域设置、权限和设备行为，按必要项补齐 | 记录实际差异，不能假报存在的摄像头、麦克风或字体能力 |
| 图形能力 | 明确 llvmpipe 与物理 GPU 的差异，评估当前虚拟化是否支持所需加速 | 实测 WebGL / WebGPU / Canvas 能力和表现；不能通过改显卡名称声称已实现硬件加速 |
| 显示行为 | 对照屏幕、工作区域、DPI、浏览器窗口及全屏切换 | 当前清晰度自适配会改变客体屏幕尺寸；应检查其与物理机窗口变化的差别，清晰不代表特征等同 |

| 网络路径 | 对照浏览器与 CLI 的真实出口，以及 DNS / IPv6 / WebRTC 路径 | 复用已有保护并记录尚未覆盖的验证，不用单次 IP 检测代替逐连接证明 |
| 真实对照 | 使用同版本、同架构、明确图形条件的物理 Linux 电脑作为参考 | 自有无账号页面产出比较报告，记录已测一致项及差异，不把某个分数当作隐身证书 |
