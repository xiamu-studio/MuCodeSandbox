# Approved Exit Measurement

The Linux VM route remains the first delivery. Add an optional, explicitly
configured IPv4 approval to strict transparent environments. Never learn or
automatically replace the approved address. Old environments retain their
existing configuration until the user chooses an address while stopped.

Measure through the VM's actual TUN using an absolute system curl path, a
clean management environment, verified HTTPS and the system CA bundle. Ignore
curlrc, inherited proxy and CA variables. Fix the measurement URL in source;
do not offer arbitrary diagnostic URLs. Reject malformed, oversized, failed,
or non-IPv4 receipts. There is no host-network fallback.

Check before publishing a started environment as running, before managed
terminal/browser/bridge access, after browser component preparation and from
the independent background monitor. Configuration and lifecycle generations
invalidate in-flight measurements. Results are display evidence, not reusable
access permissions. Busy installation/open operations do not suspend the
monitor. Quarantine immediately blocks new access, aborts the active job,
revokes connections, stops the VM and revokes again after the old job settles.

Validate startup rejection, drift, measurement loss, malformed receipts,
busy-operation cancellation and stale-response races. Use a real Linux VM,
controlled TLS measurement server and authenticated proxy. Its reported A/B
addresses are synthetic; this proves policy transitions through the real VM,
not the public addresses of a residential line. Preserve captures and target
receipts without using Claude or paid model requests.

This phase is a host-operated measurement constraint. Polling, probe duration,
stop latency, application failure/sleep, persistent guest services and
destination-dependent upstream routing remain limits. A guest lease/watchdog
and stronger connection-level exit control remain required before declaring
the final-exit and system-fault work complete. A successful measurement cannot
prove that every destination has the same public exit.
