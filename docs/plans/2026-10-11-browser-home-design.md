# 浏览器内嵌打开进度与本地首页

用户指出打开任务在画面之外显示，同时画面仍称浏览器已关闭；默认
example.com 既不能显示出口也不适合作首页。

打开任务在原浏览器画面区域显示不定量进度和日志入口，提交请求及
服务任务都纳入状态判断；在浏览器页隐藏重复的外部任务条。错误在
同一区域显示，其他环境操作仍沿用原任务提示。没有虚假的完成百分比。
普通打开保留在管理页原画面区域，“独立窗口”才打开另一个窗口；
显示方式不改变原有访问授权与防护检查。

新增静态本地首页：浏览器直接通过 HTTPS / CORS 请求 IPinfo，失败时
有限回退到 ipify。显示接收端回执 IP、地区、浏览器自身语言 / 时区，
提供网址输入和重新检测。失败清空成功状态，数据以 textContent 输出，
仅接受 HTTP / HTTPS 网址，不能由表单打开任意文件或执行脚本。

默认配置使用保留域名作为内部标识，启动器转为固定本地文件路径；
旧 example.com 占位配置兼容为内置首页，其他自定义网址保留。
客体首页文件根目录验权、只读原子发布；不增加网络端口或宿主授权。
Chrome 首页按钮返回本地页，启动仍先完成保护检查，不恢复未经批准的旧页。

验证新默认与旧配置、定制网址保留、非法导航 / 恶意文本 / 检测失败，
源代码测试和构建，以及当前签名安装包的实际加载进度、本地首页、
越南出口、网络保护及页面导航。首轮不登录 Claude，不调用付费模型。
