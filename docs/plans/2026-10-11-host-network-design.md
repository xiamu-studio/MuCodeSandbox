# 宿主网络变化防护

复用现有隔离停机链路，覆盖本轮 Linux 浏览器与 Claude Code。不是
Mac 全机网络过滤器，不需要 Network Extension 或管理员权限。

Swift 小型组件订阅 SystemConfiguration 动态状态，并每两秒重新
采样。网络摘要覆盖主出口、主服务 IPv4 / IPv6、主网卡地址 / 链路 /
Wi-Fi 标识、全局及各服务 DNS / 代理。过滤其他服务的 IPv4 / IPv6，
避免启动虚拟网卡时造成误报。空通知代表系统配置服务重启，必须撤销
旧基线。只输出 SHA-256 摘要和序号，不输出 IP、SSID 或 DNS 明文。

Node 校验消息格式、连续序号、唯一首次基线与心跳期限。退出、格式
错误、消息断序或超过 15 秒无心跳均失败关闭，不能靠后来心跳自动
恢复；需重新打开应用。正常网络变化关闭访问并异步停机，完成后仅
允许手动启动。启动流程携带宿主网络代次，变化前的异步检查不能
在事件处理结束后继续启动或激活许可。恢复后的新启动仍需原有客体
防火墙 / 出口 / 租约核验。

验证：结构化网络快照的正反对照、原生组件真实只读订阅及心跳、
包装层错误 / 缺失 / 卡死 / 退出、启动与访问竞态、实际安装包组件
被终止后的门禁与停机。物理 Wi-Fi 切换、实际休眠首包和全天运行
仍单独标记未验收；本轮不修改 Mac 网络。
