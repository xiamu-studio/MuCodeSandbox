# 本机浏览器使用与适配修正

用户要求在本机应用中打开越南沙箱浏览器，不登录 Claude，并修正底部
访问边界卡片的适配。实际观察确认文字贴卡片底部，页面滚动穿过固定
顶栏；切换页面沿用原滚动位置，会把新页面标签留在可见区域外。

保留原玻璃风格，采用固定窗口布局：侧栏、顶栏、页脚保持可见，正文
单独滚动；页面 / 环境 / 标签切换将正文滚动归零，不随状态轮询跳动。
边界卡片补齐四向内边距，小宽度纵排。浏览器增加“独立窗口”，复用
已有受认证画面和 open API，不更改 VM 网络策略或浏览器内核。

验证窗口宽度 1360 / 1000 / 860 / 390、较短高度、正文滚动及切页归零，
确认卡片文字不贴边、导航不重叠、无横向溢出。修正打入 0.4.2 桌面包，
在真实桌面再次打开浏览器，访问无账号出口页核对 VN 和 Hanoi。
原用户开发 VM 不启动，不修改 Clash 全局节点，不登录或调用 Claude。
