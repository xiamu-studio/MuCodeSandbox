# 环境页面的操作优先级

用户指出主要工具入口比防护校验提示小，视觉主次不合理。
保留玻璃风格，按使用频率重排界面：

- 总览、浏览器、Claude Code、终端占完整首排，使用 82 像素高的大按钮。
- 项目目录、网络、宿主授权及恢复设置放入次级工具行，保持可见。
- 正常防护核验和停止后的已配置状态收为约 44 像素高的状态提示。
- 直连、核验失败及异常保留完整文字和醒目提示，不用视觉收缩掩盖问题。
- 窄屏主要入口改为两列，状态细节可通过“线路与防护”查看。

仅调整前端信息层级，不修改防护判定、代理、浏览器内核或账户数据。
验证桌面 / 最小桌面宽度 / 窄屏溢出、主要按钮相对状态提示的大小、
浏览器导航点击，以及安装副本中的真实核验状态。
