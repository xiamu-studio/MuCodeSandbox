# 可读日志、出口观察和网络连接记录

用户希望从本机应用看清出口 IP 是否稳定，以及沙箱网络访问。

采用结构化记录：上方显示本轮观察时长、最后回执 IP、不同 IP 数、变化和失败；30 秒一次向两个固定公开 HTTPS 服务获取回执。定时观察不自动批准或锁定新出口，不影响已有失败关闭策略。不同目的端回执只能证明采样目标，不证明每条业务连接的真实公网来源。

连接明细读取当前 Linux 透明代理服务的 journal，记录时间、目标 IP / 域名、端口、发起代理连接或失败。采用专用 journal namespace，最多 8 MiB、内存存储；本机最多保留 10000 条结构化观察，最长 7 天。源数据超过单次读取上限或读取失败时明确显示采集中断，不伪造完整记录。不开控制端口，不解密 HTTPS，不保存请求路径、Cookie、正文、认证凭据。

当前覆盖透明代理服务的连接日志。管理 SSH / DHCP、在防火墙前被拒绝的请求、本机其他应用和每个 HTTP 请求不在逐条明细范围；未获得域名时展示实际 IP。日志中的发起连接不冒充成功或真实出口证据。

运行事件展示中文摘要，大段隔离检查 JSON 折叠到原始详情。网络页面提供采样历史、连接目标搜索、失败筛选和结构化下载。适配小窗口，不让代码块撑满日志页。

验证：解析真实格式、恶意文本 / URL 脱敏、历史限量、重复 journal 防重、读源失败 / 超量、双目的端差异 / 测量失败 / 过期、并发与停止后迟到结果拒绝、API 认证，以及本机安装包实际 VM 产生无账号连接与出口回执。原暂缓项目不恢复，不编译浏览器，不改变全局代理。
