# 跟随窗口与 Retina 的沙箱画面

问题：客体 Xvfb 固定 1280×800，客户端仅拉伸。当前 Mac 实际屏幕
2940×1912、逻辑工作区 1470×956，因此全屏缺少真实像素。

复用 Ubuntu 官方 TigerVNC / xsettingsd，替代固定大小的显示服务；
不修改、编译或重新下载浏览器。只安装小型显示组件，避免拉入编译工具。
继续使用回环监听、VNC 验证、Xauthority 和原认证 SSH 通道，禁止剪贴板
自动共享，不增加宿主文件或命令权限。

前端观察画面区域大小和本机 devicePixelRatio，按实际像素请求客体尺寸。
后端通过受认证 RFB 扩展调整显示尺寸，使用原生 XSettings 设置 DPI，
调整现有浏览器窗口，不重建浏览器资料。只有当前聚焦的查看窗口提交
尺寸，避免嵌入和独立窗口相互争抢。拖动合并请求；尺寸和像素总量限额。

返回实际确认的尺寸及浏览器密度，显示适配状态。窗口变大、全屏、退出
全屏和像素密度变化都触发重绘；失败不冒充已匹配，不修改整台 Mac 屏幕。

验证：RFB 认证 / 字段 / 应答限制、参数与权限、并发和关闭后的迟到请求；
实际桌面嵌入 / 全屏像素匹配、网页与浏览器窗口大小、输入定位、资料
保留及原有网络 / renderer / GPU 沙箱检查。其余暂缓项目不恢复。
