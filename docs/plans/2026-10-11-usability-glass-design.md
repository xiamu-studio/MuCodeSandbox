# 本机易用性与玻璃界面改造

用户要求完成待办 1～5，并检查和优化布局，采用液态玻璃风格。
不恢复内核编译、全天或其他已经暂缓的测试。

## 页面检查与取舍

现有环境页把十个标签排在一行；网络配置、防护、出口和端口映射混在
同一长页面；新用户没有明确操作入口，直连环境容易被误认为已保护。
采用浅色玻璃导航 / 工具栏与清晰正文区，保留小屏和键盘操作。
全屏透明方案会降低表单可读性；仅换颜色不能解决导航层级，因此
采用玻璃导航加任务分组。沿用本地 Avenir Next / 中文字体，不下载字体。

## 交付内容

1. Linux 浏览器单独重置：明确确认；关闭旧显示 / 调试连接；根控制的
   重置事务记录，空资料原子发布，中断后完成清理，禁止恢复旧资料。
   保留环境编号、VM 文件、代理和其他应用。首轮支持当前 Linux 路线。
2. 帮助页与首次设置清单：组件、环境、线路、防护、浏览器、备份。
   文档使用本地内容，不打开用户管理凭据或远程 CDN。
3. 无账号检测：选择受保护运行中的 Linux 环境，限定本地 SSH 转发
   和接收端，读取实际浏览器 / Worker / iframe 特征，合成登录、模拟
   Messages 流与防护复核。报告绑定环境 / 时间 / 范围，显示失败原因。
   不宣称这条回环测试证明公网、DNS 或 WebRTC 无泄漏。
4. 构建来源、测试版标识与防护状态：区分桌面 / 源码服务；未检测不
   显示已保护。摘要不含密码或私有启动链接。
5. 线路设置流程及实际验证：等待用户选择真实线路；凭据只在应用
   内填，缺少线路时不能以合成代理冒充日常公网验收。

## 布局

左侧是工作区、检测、帮助和环境；环境内容按日常使用、文件授权、
设置恢复分组。工作区有设置进度和明确的下一步；防护提示位于环境
标题下方，网络页面把配置和诊断分层。玻璃只在导航 / 浮动控件使用
有限模糊，保留对比度、减少动态效果和可读的禁用状态。

## 验证

重置使用合成旧 Cookie / localStorage / IndexedDB / 历史及文件标记，
验证空白、其他资料保留、旧连接失效、重启和中断恢复 / 路径逃逸拒绝。
API 验证来源、确认参数、任务串行和失败记录。UI 检查实际入口、对话框、
帮助、检测报告、线路步骤与 1360 / 860 / 390 宽布局，保存截图。
构建新候选后验证签名和对应功能；不把旧包 13 项证据全部迁移为新包。
