# 内容滚动区与导航间距

用户截图中，桌面画面滚到上沿后与面包屑导航紧贴，客体窗口上沿部分被滚动视口裁掉，看起来像重叠。

代码中 main 已是固定高度的列布局，topbar 单独占位，main-content 是唯一内容滚动区。保留这个结构，在滚动区上方增加不随内容滚走的12px间距，窄窗口8px；同时将早期样式中的sticky声明统一为relative，避免前后样式表达矛盾。

不采用给客体加额外分辨率 / DPI，也不将桌面画面固定悬浮到导航之上。检验三档宽度、内容滚到顶部 / 中部 / 底部时导航与滚动区域没有交叉、间距仍在、页脚可见且页面没有水平溢出。最终检查必须在更新后的本机应用中完成。
