# 客户端安装状态误显示修正

问题：VM 因出口回执不足被保护停机后，安装状态接口返回空列表。界面把空列表、首次检测和检测失败统一显示成“未安装”，容易误导用户重新下载。客户端文件没有因此删除。

采用直接表达未知状态的方案，不新增持久缓存。持久缓存虽然可以展示上次安装版本，但需要绑定整环境重建、导入与卸载，容易又把旧环境的状态带入新环境。

规则：环境未运行显示“启动后检测”；运行中的首次查询显示“正在检测”；读取失败显示“检测失败”并可刷新。只有收到当前环境、当前运行状态下的明确缺包结果，才显示“未安装”和安装按钮。检测失败或未知时不允许从该卡片发起安装。结果绑定环境 ID 和运行状态，切换时不沿用旧结果。防护停机原因直接显示在桌面页，不放宽网络策略。

验证：隔离 UI 夹具覆盖停止、失败、恢复、确认缺包及环境切换；构建检查和本机应用安装包验证；实际本机窗口核对停止状态。此次不重装客户端，不清理环境，不重跑账号、长时间和断线测试。
