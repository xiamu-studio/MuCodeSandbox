# 环境操作区与桌面提示排版

用户标出两处：标题右侧状态孤立在按钮上方；桌面介绍与两条横幅重复占据大段高度，客户端卡片被挤出首屏。

方案采用局部调整，保留现有色彩和导航。右侧状态、带文字的重启及主启动 / 停止按钮单行居中；窄窗口移到标题下一行，状态靠左、操作靠右。不采用新增大控制卡，避免继续增加空白。

桌面标题与简短说明放在同一个标题组。仅保留一块当前条件提示：已配置网络但环境停止时，只解释启动；防护失败时，显示原因和查看网络入口；未配置网络时，指导配置。保留全部错误信息，不用蓝色和橙色两条重复提醒。客户端卡片不重复长段停止说明。资料与生命周期说明放入可展开帮助，继续保留清理边界。

验证只覆盖本次 UI：隔离夹具下运行 / 停止 / 防护错误，1320 / 800 / 390px 显示、右侧控制对齐、单一提示、客户端卡片位置及既有安装状态逻辑；生产构建、应用包检查及本机窗口核对。网络与 VM 运行逻辑不改变，不重装客户端。
