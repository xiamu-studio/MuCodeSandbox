# 网络记录：目标网站与沙箱出口

用户要求目标列显示网址，沙箱出口列显示 IP。保留现有透明代理与保护策略，不增加 HTTPS 解密、公开控制端口或浏览器内核修改。

- 同一 sing-box 连接 ID 的入站域名与解析地址对照，给出该连接请求的域名。连接 ID 按客体启动和服务实例隔离。
- 只有 DNS 记录时，按 TTL 对照 IP；显示“DNS 对照”，共享 CDN IP 存在多个域名时不猜测。缓存有容量、时间限制，环境重启或配置变化清空。
- “目标网址”仅保留网站域名；服务器 IP 放在其下方。不保存路径、查询参数、Cookie、正文。
- 出口核验成功或失败均保存时间标记。连接发生前 45 秒内最近一次成功核验可作为上下文；之后的回执不补填过去，失败和过期不沿用旧回执。未启用锁定时可显示 90 秒内最近的检测回执，标签区别于核验。
- 每条连接保存自己的出口上下文；重启应用、出口变化后不会用当前 IP 改写旧记录。它是检测端回执，不是目的网站对每条连接的确认。
- 验证：跨批次连接关联、共享 IP 歧义、DNS TTL、跨启动隔离、未来/失败/过期出口拒绝；界面搜索、旧记录空态和窄窗口；最终更新本机应用再检查真实记录。
