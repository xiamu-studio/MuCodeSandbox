# 文件与中文输入交互（0.4.26）

目标：让 Linux 沙箱内的日常文件上传、中文输入与英文翻译更方便，保留现有网络保护及环境隔离。

## 已实现

- 文件可以直接拖到已连接的沙箱画面；也可以从工具栏“文件与粘贴”选择文件。显示上传进度、服务器实际保存路径及同名另存结果。
- 文件仅传入当前环境 `/home/dev/Transfers/Incoming`，不会自动提交给网站。点击“复制路径到沙箱”，在网站文件选择框按 Ctrl+L、Ctrl+V、回车即可选择；确认上传仍由用户操作。
- 整批先检查单文件 25 MiB 限制；中途失败保留成功项，停止后续项，明确说明未确认的文件。目录及大文件仍走项目目录挂载。
- “中文输入”提供 Mac 原生输入法文本区。先点沙箱输入框，再输入草稿，点击“粘贴到沙箱”或按 Cmd+Enter。输入法选词回车不提交；粘贴不自动按回车。收起输入栏保留草稿，切换环境清除该组件草稿，不写磁盘。
- 点击“Google 翻译小窗”才把当前草稿交给 Google（最多 5000 字），在当前沙箱已打开的受管理浏览器中新建小窗。再次点击只替换此功能创建的上一个小窗。
- 翻译后手动复制英文，点击“取回译文”读取沙箱剪贴板到草稿，核对后再粘贴到目标输入框。不会自动读取 Mac 剪贴板或自动向聊天发送。
- 翻译、文件和剪贴板操作继续执行现有保护检查，不改变语言、时区、出口规则。

## 0.4.28 小窗内翻译

原文旁点击“翻译成英文”，译文在同一个小浮窗显示并可编辑。点击“粘贴译文”才写入目标输入框并收起；不自动回车。原文仍保留，修改原文会丢弃旧译文，避免错贴。原文/译文只在组件内存保存，不记入应用日志。

请求通过现有受保护 Linux guest 执行，前后复核访问许可和环境版本，固定 HTTPS Google 公共网页翻译兼容接口（translate.googleapis.com/translate_a/single，非付费 Cloud Translation API）。每次最多 2000 字，设置连接/总耗时与响应大小限制；不跟随重定向、不关闭 TLS 校验、不回退宿主直连。只在用户点击时提交原文，界面说明接收方。此公共接口可能限流或改变，不能承诺可用性。

构建、3 项翻译后端测试和 13 项合成界面检查通过；覆盖固定目标、文本走 stdin、撤销许可不交付结果、错误脱敏、译文编辑和显式粘贴、旧译文清理。没有主动请求 Google 翻译或 AI 网站，真实服务可用性仍待用户手动验证。文件选择旧问题未在本轮处理。

## 0.4.29 小窗剪贴板与右键

原文和可编辑译文各增加紧凑的“复制 / 粘贴 / 清空”按钮。复制优先使用选中文字，无选中时复制全文；粘贴在光标处插入或替换选中部分。只在显式点击时读取 Mac 剪贴板，不自动发送到沙箱。向沙箱粘贴仍由独立的“粘贴原文 / 粘贴译文”按钮触发。清空译文后保留可编辑框。

主窗口和独立查看窗口中的本地可编辑控件提供原生右键菜单：撤销、重做、剪切、复制、粘贴、全选，按编辑状态启用。菜单仅处理本应用同源可编辑控件，不拦截远端画布右键。

0.4.29 / 36d86f76e6323d3b 已安装。构建、15 项合成 UI 检查、安装包完整性与深度严格临时签名检查通过。实际本机搜索输入框以临时测试文字确认了同一原生右键处理器的中文菜单及选中时剪切/复制可用，测试文字已清除；小窗的光标粘贴、选区复制和空译文保留通过生产组件合成测试。未打开真实 AI 网站或请求外部翻译接口。
