# 状态、清理与恢复展示优化

用户授权：参考 CCBaga，按适合当前 MuCodeSandbox 的范围优化。保留现有 VPS、至少两个独立一致回执、失败停机、同环境保存及重建 / 删除全清语义。

选择小范围产品改进：复用现有 API，在总览显示配置与读取结果，统一清理确认及失败操作入口。单纯改文案不能解决实际状态缺失；引入身份保险库、指纹内核、全新网络部署则超出当前目标。

1. 共用防护读取，避免总览和顶部重复轮询。显示核验时间，过期 / 失败 / 未运行不能沿用绿色成功。
2. 总览展示联网防护、出口 IP、浏览器地区及安装版本。读取浏览器现有页面，不启动、跳转或登录。授权状态由真实授权列表计算。
3. 浏览器重置、整环境重建、环境删除采用同一范围说明组件；区分永久清除和保留内容。执行中禁止重复提交或关闭确认，失败留在当前确认窗。
4. 最近操作显示失败原因、执行耗时和相应检查入口；只导航，不自动重复删除或放宽防护。
5. 验证：状态过期及不足回执单元测试、临时数据 UI 场景、构建、相关防护回归，随后打包并核对本机交付。
