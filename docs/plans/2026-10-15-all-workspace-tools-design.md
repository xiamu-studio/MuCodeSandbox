# 浏览器、桌面与 CLI 共用快捷工具

用户要求所有入口均能使用文件与粘贴、中文输入与翻译。复用现有工具组件，统一按钮和浮窗；不新增顶部大面板。桌面查看器原本已有同样工具，保留；给 Shell 和 Claude Code 的终端头部补齐。

GUI 的粘贴仍写客体剪贴板后按 Ctrl+V；CLI 直接走已授权的当前终端 WebSocket / xterm 粘贴，不依赖 Chrome 或 X11 剪贴板，不自动追加回车。终端选择文字仅在明确点击后取回；没有选择时提示，不读取 Mac 剪贴板。文件沿用原受保护接口和当前环境目录，粘贴到 Shell 的路径使用单引号转义。

多行或 Tab 仅在终端已启用 bracketed paste 时允许；否则明确拒绝并保留草稿，不悄悄拆行执行。拒绝粘贴控制字符或可关闭 bracketed paste 的转义序列。发送时检查当前页面仍活跃、连接仍有效；Unicode 分块不得切断代理对。显式“回车”按钮仍由用户主动点击。

隐藏页保留草稿但不可发送，切换环境卸载原状态；文件队列已有撤销规则保留。翻译仅用户点击时走现有客体 Google 端点，不新增线上测试或宿主直连；前一轮错误分类一起交付，不声称解决未知线上失败根因。

验证：真实生产组件 + 本地 RFB/终端回执，覆盖所有入口、中文/译文、命令未执行、多行与 ESC 边界、文件路径引用、断连/隐藏/重新连接、草稿隔离与窄屏；不启动真实 AI 客户端、访问 AI 页面或调用外部翻译服务。
