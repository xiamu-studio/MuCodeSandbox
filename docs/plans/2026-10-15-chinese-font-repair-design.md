# 中文显示修复

用户已授权直接修复，保留现有防护。当前中文默认回退 Unifont；只补装 Ubuntu 官方 `fonts-noto-cjk`，保留 Unifont 作为缺字兜底，不恢复文泉驿、不移除其他语言字体、不更改语言或时区。

1. 记录当前防护状态、规则摘要和浏览器 PID。
2. apt 模拟确认只新增字体包。实际下载使用受防火墙约束的 dev 用户，禁止服务自动重启，不升级其他包。
3. 更新字体缓存，核对普通与加粗中文匹配，并以独立空白资料生成本地文字截图。不访问 AI 服务，不读取现有网页、Cookie 或剪贴板。
4. 重核防护摘要、有效许可和两个独立出口回执。将字体补入新环境依赖清单。

不重置现有资料。当前浏览器若缓存字体，先确认刷新能力，再说明是否需要重开；不擅自恢复或访问已有真实网站。
