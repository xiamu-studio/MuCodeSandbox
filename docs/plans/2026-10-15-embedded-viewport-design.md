# 小窗口完整画面

用户报告嵌入浏览器底部被应用底栏挡住。已用相同主区 / 顶栏 / 底栏 CSS 和本地 RFB 夹具复现：1320×650 窗口内画面底边 694px，而内容区到 600px 已结束；仅滚动外层到画面顶部也不足以完整显示。

嵌入查看器改为：实际滚动容器的客户高度扣除上下内边距，作为查看器最大高度。画面区域允许在纵向 flex 布局中缩小，原有 `guestPresentation` 同时按宽高等比适配。进入浏览器 / 桌面页时，以及窗口缩小时当前正在看的画面，移到滚动区域内；不在用户查看其他详情时抢回滚动位置。

观察滚动容器与工具栏的尺寸，使用 requestAnimationFrame 合并读取与调整；隐藏页释放观察，不持续轮询。全屏和独立窗口保留原有布局；固定桌面尺寸 / 2×、RFB 权限、虚拟机、资料和网络规则不变。

验收使用本地合成画面：多种宽高、折行工具栏、右下角点击映射、全屏返回、隐藏页重新进入与固定桌面不变。更新本机应用时正常停止，不访问用户实际 AI 网页；将上轮已完成的中文字体依赖一并打包。
