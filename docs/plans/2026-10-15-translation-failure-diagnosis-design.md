# 翻译失败诊断

用户截图中 Google 翻译返回统一“限流或超时”提示，尚无实际状态码证据。先用本地合成输入检查请求格式与沙箱命令通道：两者可执行，不能据此宣布线上服务已恢复。

固定同一 Google HTTPS 端点，继续使用客体 dev 用户、透明代理和原有授权前后检查；不读取 Mac 剪贴板、不发送截图原文、不尝试宿主直连或其他供应商、不忽略 TLS、不跟随重定向。原文与程序经 stdin 传输，缩短 SSH 命令；结果只交付译文或枚举化错误，不交付服务响应正文、请求 URL 或原文。

区分 HTTP 429 / 401 / 403 / 其他非成功状态、DNS、连接、TLS、超时、响应过大与无效回复；界面显示相应的普通语言提示，保留原文。请求仍有原有的 6 秒连接、18 秒 HTTP、20 秒 Python、24 秒客体任务上限，不增加自动重试或切换出口。

本地用合成 subprocess 回执验证所有类型和原文不泄露，执行相关已有界面检查。遵守 AGENTS.md，在线诊断等待用户明确允许固定无敏感测试词，不把合成译文算成 Google 实际可用。
