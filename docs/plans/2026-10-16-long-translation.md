# Long text translation and explicit guest retrieval

Scope authorized by user: remove the impractical 2,000-character translation cap, make guest-copy → translation one explicit action, expand long original/result text for reading, and retain line/paragraph/list/code formatting. Keep the compact normal tool and existing Linux network, account, file and clipboard boundaries.

Implementation: shared 16,000 UTF-16-unit source / 64,000-unit result limits across UI, Zod and fixed Python; 32,768 output tokens and a bounded 90-second provider timeout. No chunking, retries, automatic provider changes or host fallback. Fixed translation-only prompt explicitly preserves newlines, blank lines, indentation, Markdown, code and URLs. UI/server pass text unmodified; a model's formatting compliance is not guaranteed.

The shared GuestTextInput is used by browser, desktop, CLI and shell. A top-level “取回并翻译” button explicitly reads Linux X11 clipboard for graphical surfaces or current terminal selection for terminals, then makes one guarded translation request. Empty/oversized reads preserve the existing draft and never translate. Failed translation retains the fetched source. There is no passive clipboard polling, Mac clipboard read or automatic paste/Enter.

“放大查看” uses the existing keyboard-trapped Modal in a portal inside the current fullscreen owner (or body). It reuses the same draft/result state. Original/result appear side by side on wide screens and vertically on small screens in one scrollable body; 14–24px reader-only type controls do not change guest fonts. Shrinking retains edits and restores focus. Disconnect or owner change invalidates pending UI results and aborts fetch; the guest job may still finish under its existing bounded supervisor and guard. Do not claim browser abort cancels a paid provider request.

Verification: real production Python with synthetic curl responses, long Unicode and UTF-16 boundaries, exact whitespace/Markdown preservation, scoped API auth/key-revision checks, explicit clipboard and one-call behavior, no Enter, empty/oversize/failure recovery, disconnect before/after model submission, narrow and fullscreen geometry, keyboard close/focus, file-tool and four-surface regressions, fail-closed quorum/lease/task tests, normal package verification. No user key extraction, real paid model calls, AI browser pages or logins. Build candidate before asking to restart because current popup drafts are volatile.
