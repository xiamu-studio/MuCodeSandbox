# 连接列表直接显示历史出口

用户要求利用日志右侧空间，直接看到出口 IP，便于对照稳定性。

- 宽屏每条记录左侧保留目标、时间和事件，右侧常显“当时检测出口”、原始出口 IP 和检测时间；窄屏换行，不横向裁切。
- 只使用这条记录已有的 exitIp / exitCheckedAt。没有记录显示“未记录”，不拿当前摘要 IP 补历史，不新增“稳定”或目的站已确认的判断。
- “服务器”明确为“网站服务器 IP”。详情保留证据来源和适用范围，不重复显示同一个出口。
- 只改 React 展示和 CSS，后台、采集、存储、核验、双回执、许可、防火墙与路由不变。
- 用合成历史验证不同出口、缺失记录、默认可见、宽窄屏排布；构建打包后比较全部后台和桌面桥接字节。更新前让用户保存窗口草稿。
