# 快捷工具布局与截图交付

## 范围

用户要求重整文件/剪贴板面板和翻译按钮层级，并导出全部工具主页面与弹窗截图，不出现Claude相关字样。沿用当前字体、配色、网络与安全边界。

- 文件面板以文件、图片、文字三个同级入口组织。图片不再插在文件列表上方；文件上传与刷新统一放在文件区右上方，目录导航和列表保持主体位置，说明收起。
- 翻译区方向选择在左，翻译与粘贴在右，粘贴原文为最右主操作；放大状态沿用同一规则，小屏换行且按钮不被裁切。取回并翻译默认中文及手选优先规则保持。
- 仅重排组件标记与CSS，不改文件队列、认证、授权、防护、剪贴板触发和翻译请求逻辑。
- 截图使用独立Vite示例环境、合成API与中性本地画面，不读取真实文件/剪贴板/Key，不连接用户VM或AI站点。截图专用文案替换Claude/Anthropic等品牌及相关域名，覆盖弹窗后面的主页面；不修改正式产品名称。
- 交付独立PNG、单张缩略总览、离线浏览索引与ZIP。索引说明是生产组件的示例展示截图，不冒充真实账号、网络、防护或模型验收。

## 验证

相关文件、图片、翻译UI回归；宽/窄屏位置、溢出和底部动作检查；包内后台/桌面桥接与现有安装逐字节对照。截图逐张核对可见文本、页面错误与禁用品牌，并视觉检查总览及关键弹窗。
