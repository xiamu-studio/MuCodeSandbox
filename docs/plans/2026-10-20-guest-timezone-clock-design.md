# 查看器沙箱时区时钟

在环境名称 / Linux 标记旁显示日期、星期、时间和夏令时缩写。星期中英文同时显示：空间宽裕时为“星期二 Tuesday”，窄区域为“周二 Tue”；窄窗口省略日期，悬停始终提供完整日期、双语星期和IANA时区。

使用已有`identity.timezone`和当前时刻进行Intl格式化，夏令时由时区规则处理。它是按配置时区显示的界面时钟，不把主机时间换算当成读取VM系统时钟的校准结果；tooltip明确来源。不改VM时区或系统时钟，不新增联网、SSH或防护请求。

嵌入浏览器和桌面查看器传入现有环境时区；独立窗口复用既有的环境名称元数据读取，切换环境清除旧时区对应关系。未知/无效时区有明确占位，不回退成Mac时区。

仅时钟组件每秒刷新；隐藏标签、页面不可见时暂停，恢复时立即刷新，不触发查看器重连或尺寸请求。保留既有字体和工具排列，只在标题区域使用容器空间决定星期全称或缩写。

本地合成页面核对跨日、双语星期、夏令时跳变、环境/时区变化、隐藏与恢复、独立窗口，以及窄屏工具可达性。不得访问AI站点或真实翻译。
