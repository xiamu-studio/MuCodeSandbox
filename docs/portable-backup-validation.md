# 加密环境备份验证

日期：2026-10-10。本机 Apple Silicon / macOS 26.3.1 / Node 24.15.0 / Lima 2.2.0，客体 Ubuntu 24.04 ARM64。验证不登录 Claude，付费调用 0。

## 实现范围

离线快照可导出为 `.mu-backup`：标准 tar / gzip、AES-256-GCM、随机 salt / IV、scrypt 派生密钥；版本头参与认证。密码至少 12 个字符，不写入任务、日志或命令参数。备份含 Linux 磁盘、浏览器资料和网络凭据，密码丢失不可恢复。

导入先完整验证密文，再解析限定的清单与磁盘。拒绝链接、路径穿越、重复或额外条目、超额内容及错误磁盘哈希。使用私有暂存目录和稀疏磁盘，检查容量；导出排他发布，保留已有同名文件。导入创建新环境和 VZ 硬件身份，将凭据重新加密，移除宿主共享目录、端口和桥接授权。客体系统、应用资料及其自身标识随磁盘保留。

正常生命周期从认证种子镜像创建 VM。严格环境要求当前版本的保守开机防护；首次启动完成管理密钥撤销和新密钥复核前，不能被恢复为可用状态。后续正常启动也替换管理授权，避免旧公钥再次加入。

## 发现与修复

`portable-backups-before-management-key-revocation.json` 保留真实失败：导入虽然生成新本机密钥，但 cloud-init 同时保留旧公钥。修复为开放环境前替换授权、复核新密钥并持久记录初始化完成。修后实际旧密钥登录拒绝。另修正 root 授权文件检查必须通过 sudo 执行，避免普通用户因目录权限而跳过清理。

`portable-backups-before-curl-quiet-fix.json` 为测试断言错误：curl 进度被并入输出。修正静默模式后重新运行，没有修改产品网络策略。`portable-backups-before-root-key-check.json` 保留增加 root 授权正向夹具前的一次通过记录。

## 尚未验收

- 实际第二台 Mac、不同主机的资源和版本兼容；同机独立数据目录不等同跨机器通过。
- Claude 等真实服务账户迁移；已验证真实 Chromium 的本地合成 Cookie / 登录状态与网站数据迁移，没有使用真实账户。
- 导入磁盘写入 / 发布 / 数据库提交等更多中断窗口、整机断电、实际整盘 ENOSPC、不同外接文件系统。真实 SIGKILL 目前覆盖认证解密完成后的暂存窗口；导出排他硬链接发布目前只在本机 APFS 实测。
- 完整系统设备标识重建；备份恢复保留客体系统和应用资料，不能用于证明所有环境完全独立。
- 新包的快照事务恢复 / 故障全流程；包内已验真实快照创建、加密备份导出 / 导入及新恢复 VM / 浏览器启动和重启，不能替代快照事务故障验收。原 `5f30519` 候选保留不变，不包含备份。Electron 原生文件选择对话框尚未实际操作验收，本轮在界面输入路径。

复现入口：`npm run test:backups`、`npm run test:backups-browser`、`npm run test:backups-packaged`、`npm run test:backups-ui`。包内入口要求已生成 `release/backup-candidate` 的应用。实际 VM 测试创建并清理本测试拥有的 VM；失败保留隔离目录以便检查。结果只证明脚本明确覆盖的场景。
