# 防护历史加载与环境切换（0.4.35）

## 实际发现

防护记录接口短暂失败后，生产组件把读取错误和操作错误放在同一状态。下一轮成功轮询更新了事件，但没有清除旧错误；合成 503 → 200 已在修改前复现（十秒后仍显示读取失败）。空历史首次加载时也直接显示“尚无防护停机记录”。顶部防护组件在环境切换时复用，旧重试请求的结果可能写入新环境的组件。

## 修复

- 读取错误和操作错误分开维护，成功刷新仅清除读取错误。
- 首次等待显示“正在读取防护记录”；请求失败明确提示暂时不能确认，而不是显示空历史。
- 已有旧记录时保留记录并提示可能不是最新；没有未解决故障时，顶部仍能报告历史读取失败。
- 顶部防护组件按环境 ID 分配实例，切换环境销毁旧状态，隔离晚到的重试结果。
