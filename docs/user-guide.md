# MuCodeSandbox 后台使用指南

## 沙箱时区时间（0.4.64）

浏览器和桌面查看器标题旁显示对应时区的日期、中英文星期和时间，例如`10/20 星期二 Tuesday 05:34:56 PDT`。较窄时简写为`周二 Tue`，悬停可查看完整日期与时区。时间按沙箱配置的时区换算，包含夏令时，后台标签暂停显示刷新；这不会修改VM或Mac的系统时钟。

## 中文输入与翻译浮窗（0.4.63）

拖动标题可以移动小窗或放大阅读窗口，拖动右下角可调整整个窗口大小。点小窗外部收起，草稿和换行保留；重开应用前仍需自行保存草稿。浮窗限于当前应用窗口，暂不支持拖到另一屏独立显示。

清空原文或删空后恢复自动互译；当前草稿里手选的方向保留。只有数字或符号时需要手选翻译方向。“取回并翻译”未手选时仍默认英译中，编辑取回文字会回到自动互译。

画面偶发缺失时，可在查看器的“显示设置”点“重绘画面”，保持当前网页和连接。它只能重新取得和显示画面，不能保证修复网站本身的绘制问题。

## 防护停机后怎么处理（0.4.18）

出现“需处理”时，环境页会显示“防护停机已记录”。点“原因与修复”看失败时间、批准 IP、当时收到的 IP、各检测端结果、停机结果和修复步骤。“日志”页保留最近100次防护事件，可下载单次诊断。旧版错误只能显示摘要，不会补造过去的回执。

- IP确实变化：先恢复原线路；确实需要新线路时，由你在网络页核对并修改批准值。系统不会自动接受新IP。
- 回执不足 / 超时：不代表已发现不同IP。查看哪些端失败，确认VPS或代理在线、端口正确，再点“重试核验并启动”。
- TLS / 认证 / DNS：按卡片核对证书名称、代理账号或受控DNS；不关闭校验、出口锁定或防火墙。
- 休眠 / 应用退出使许可失效：恢复本机网络，重新核验启动，不需要删除环境。

提交重试不等于已经恢复。只有当前配置通过启动、防护及所需一致回执检查，才记录恢复时间和证明；原始故障保留。重试失败继续关闭访问并留下记录。恢复只启动环境，请再打开所需客户端；不要自动重复提交中断的任务。磁盘无法保存事件时会提示暂存内存，请先导出诊断并检查空间。

0.4.17 起：浏览器、桌面应用和终端可以同时运行，切换功能页保留连接。已打开客户端的按钮为“显示窗口”。客户端打开登录网页会转到同一沙箱中的受管浏览器；固定客户端返回协议会交回同一资料目录。正常关闭仅关闭选定程序，重建 / 删除环境仍彻底清理。首轮不输入真实账号。按你的选择，客户端不调用密码保险箱；本地登录凭据不应视为安全加密保存。

## 文件传输、复制粘贴

浏览器或桌面画面工具栏点“文件与粘贴”，两种功能都共用当前沙箱。

- 文件传输：选“文件传输”，拖入 Mac 文件或点“选择文件上传”，每个文件最多150 MiB，显示传入字节进度；传完后等待沙箱保存确认。新文件默认保存在 `/home/dev/Downloads`，确认后自动显示下载目录。旧传入文件可点“移到下载目录”，也可直接“打开所在文件夹”。重复文件名另存，不覆盖原文件。项目共享文件位于配置的 `/workspace/...`，可从文件面板“项目目录”入口打开；不是下载或传入文件夹。
- 下载到 Mac：在沙箱应用里保存到 `/home/dev/Downloads` 或 `/home/dev/Transfers/Outgoing`，在面板中“刷新文件”，对选定文件点“下载到 Mac”。只列这三个文件夹的普通文件。
- Mac 文字进沙箱：在面板输入框用 ⌘V 粘贴，点“发送到沙箱剪贴板”，再到沙箱目标输入框按 Ctrl+V。
- 沙箱文字到 Mac：在沙箱选文字并 Ctrl+C，回到面板点“取回沙箱文字”，核对后点“复制到 Mac”，最后用 ⌘V。最多64 KiB，只传普通文本。

不会自动读取或同步 Mac 剪贴板；关闭面板清空预览。上传文件留在当前 VM，重建或删除环境会清除，Mac 原文件不受影响。整个项目或大文件可继续使用“项目目录”的显式共享。

2026-10-12 按要求仅移除沙箱里的文泉驿正黑 `fonts-wqy-zenhei`，新环境不再自动安装这款字体；未删除 Mac 字体。中文使用剩余系统字体回退。第三方评分不能证明官方安全或保证账号不会受限。

## 打开受保护的桌面客户端

1. 选“美国 VPS · 全新环境”，启动并等候防护核验。
2. 点“桌面应用”。当前已安装官方 Grok Bot ARM64 0.68.1 和 Claude Desktop ARM64 2.31226.1。
3. 点对应的“打开客户端”，通过进程保护和出口检查后显示 Linux 画面。首轮停在登录之前，不输入账号、不调用收费模型。
4. “关闭”只关闭这个客户端，资料保留。0.4.15 起客户端直接启动独立显示服务，不先打开 Chrome；普通关闭 Chrome 不影响客户端，停止环境仍关闭全部程序。不要把关显示窗口当成清除资料。
5. 按你的选择，客户端使用 basic 本地存储，不创建或解锁密码保险箱。正常关闭保留当前环境资料；这不提供钥匙环加密保护。重建或删除清除 VM 内客户端资料，Mac 原文件与另存备份保留。本轮不验证真实账号持久化。

Grok Bot 的云电脑、云端浏览器与任务出口不由本机沙箱控制。Claude Linux beta 的 Cowork 需要 KVM；当前客体没有 `/dev/kvm`，Computer Use / Dictation 也不在当前已验范围。普通客户端窗口可测试不代表这些模式全部可用。

## 清除所有客户端并创建全新环境

- **普通关闭 / 重开 / 查看切换**：保留当前环境内的资料。
- **重置浏览器资料**：只清 Chrome，不清桌面应用或整个 Linux。
- **设置 → 彻底重建环境 → 确认清除并创建全新环境**：删除旧客体整盘、客户端数据 / 密钥环 / 缓存 / 本地项目与本应用快照、导入和恢复副本；生成新 ID / 新磁盘，不迁移旧资料，需重新安装客户端。
- **删除环境**：同样删除旧环境的整个磁盘及本应用管理副本，不自动创建替代环境。

重建保留选定网络与地区，取消共享、桥接及端口。不会改变固定出口 IP，不删除网站后台记录、Grok 云电脑或你手动另存的外部备份，也不删除本机共享源目录。只有任务显示完成才算清理完成；失败时不要把替代环境当成已验收。

## 出口核验与专用连接

“网络”页的“出口核验状态”显示批准 IP、本轮检测 IP 和独立回执。核验使用三个 HTTPS 接收端，至少两处新回执一致；一个明确超时可以由另外两处一致回执补足。任何回执 IP 不一致、证书 / DNS / 认证 / 格式错误或不足两处回执均停止联网。观察历史里的单处查询失败会保留，不把它隐藏为成功。

VPS SSH 连接已作为当前 Mac 用户的登录服务启动，不需要每次输入 Root 密码。专用连接只绑定 Wi-Fi en0，并仅监听本机回环端口；换其他网络接口时可能连接失败，应重新检查，不能随意关闭防护。“Root 密码”和本机 SSH 私钥不要填写进沙箱代理密码框。

## 先理解这个后台

这是自己 Mac 上的管理界面，不是云服务器后台。你在这里创建、启动和
停止独立环境，管理它们的浏览器、文件、网络和备份。

当前推荐使用“Linux 沙箱”：网页和开发命令在 Linux 虚拟机里面运行，
Mac 负责显示画面和接收键鼠操作。选“本机浏览器”则是在 Mac 上运行，
只有独立浏览资料等功能，没有 Linux 防火墙的防泄漏保护。

## 新建一个 Linux 沙箱

| 字段 | 怎么填 |
| --- | --- |
| 类型 | 选择“Linux 沙箱”，不要误选“本机浏览器” |
| 环境名称 | 自己能识别即可，例如“日常开发” |
| CPU / 内存 | 界面默认 2 核、最多取 4 GB 内存；先用默认值，不同时开很多环境 |
| 磁盘容量 | 默认 30 GiB，为虚拟磁盘容量；实际占用随数据增长，快照和备份也需要空间 |
| 项目目录 | 初次可以不加；要加时只选一个专用项目文件夹，优先只读 |
| 语言 / 时区 | 按实际使用地区设置，例如 `zh-TW` / `Asia/Taipei` |
| 网络出口 | 按你实际持有的代理或隧道配置填写，不会自动提供住宅 IP |

语言和时区配置不会把 Linux 变成 Mac，也不会保证某个网站不会封号。
当前保留实际 Linux、字体和图形信息，不伪装成另一台完整设备。

## 线路怎么填

| 模式 | 需要准备 | 说明 |
| --- | --- | --- |
| HTTP / SOCKS5 代理 | 服务器、端口，以及提供商要求的用户名和密码 | 第一跳不自带传输加密；需要强制出口时勾选“仅代理联网（Linux 防火墙）”并选择“透明代理” |
| HTTPS 代理 | 上述信息，加“代理证书服务器名称”；必要时提供商给出 CA | HTTPS 指连接代理本身加密，不是因为你访问的网站是 HTTPS 就选它 |
| WireGuard · 测试 | 端点 IPv4、端口、隧道 IPv4 /32、对端公钥、自己的私钥等 | 只在提供商确实提供 WireGuard 配置时选择；住宅公网线路未验收 |
| 直连 | 无 | 使用正常网络出口，没有强制代理防护，不能当成隐私线路 |

不要根据猜测填写端口，也不要把订阅链接直接填进“代理服务器”。
住宅代理需要自行提供；普通宽带或本机代理软件不自动等于住宅代理服务。

如果服务在当前 Mac 的回环地址上，按它实际提供的地址和端口填写。
管理器会处理客体与宿主之间的连接，不需要自己在虚拟机里填写 Mac 的局域网地址。

“出口变化时停机”只有在你知道并批准了固定公网 IPv4 时才开启。
这里填的是最终网站看到的出口，不一定等于代理服务器地址。动态出口
可能触发拒绝启动或停机；不要填写一个随意查到的 IP 来消除提示。

默认加密 DNS 配置一般不需要自行改动。若线路要求其他服务，必须填写
相互匹配的服务地址、TLS 名称、端口和请求路径，不能只改其中一个字段。

## 启动后怎么检查

1. 点环境右上角“启动”，等待状态成为运行中。
2. 进入“网络”，点击“检测防护”。严格透明配置应看到防火墙、透明代理、
   开机防护生效，规则一致，透明路由和受控 DNS 生效。
3. 点击“检测出口”，查看 Linux 环境实际检测到的公网 IP。
4. 若启用了出口锁定，同时确认“出口核验状态”显示“检测一致”。
5. 进入“浏览器”，打开浏览器；可以点“检测特征”查看页面语言、时区等实际值。

“环境运行中”只说明虚拟机在运行，“检测出口成功”只说明该次请求成功，
二者都不能单独证明所有防护通过。`--`、尚未检测或未通过时，先看日志。
严格模式连接失败时不要为了联网而改成直连。

修改网络、地区、资源或共享目录前，先停止环境；相关编辑入口在运行时会禁用。

| 系统设置 | 查看运行组件、本机资源及实际数据目录 |
| 操作记录 | 看启动、安装、恢复等后台任务是否成功，查看失败原因 |
| 总览 | 查看所选环境状态和资源 |
| 项目目录 | 设置持续共享给虚拟机的文件夹；修改需先停机 |
| 网络 | 配置线路，检测防护和出口；初次不必配置端口映射 |
| 浏览器 | 打开 Linux 浏览器、检测特征、查看版本、手动更新或恢复 |
| Claude Code | 安装和打开官方 CLI；本轮先不登录、不发付费请求 |
| 终端 | 执行 Linux 命令，工作发生在虚拟机里 |
| 日志 | 看出口 IP 观察、连接 / DNS、中文运行事件，筛选目标和下载记录 |
| 设置 | 修改名称、地区、资源，按条件扩容；删除环境也在这里 |
| 快照 | 停机后保存 / 恢复 Linux 磁盘和配置，导出加密备份 |
| 宿主授权 | 临时批准对某个 Mac 目录的文件操作或有限 Git 操作 |

停止会保留虚拟机磁盘；删除环境会移除其虚拟机和所属资料。
共享的 Mac 项目目录不随环境删除，但它自己需要另做备份。

## 删除重建能重置哪些内容

0.4.1 新增单独重置：启动 Linux 环境后进入“浏览器 → 重置浏览器资料”，
阅读确认范围后点击“确认清除浏览器资料”。旧浏览器会关闭；任务成功
后重新打开，使用新的空白资料。虚拟机、项目文件、线路和 Claude Code
配置保留。失败时看操作记录，不把提交任务当成已清除；中断恢复会继续
完成空白重置，不把旧资料自动还原。旧快照或备份仍可能带回旧资料。

环境可以删除后重新创建。操作入口是当前环境的“设置 → 删除环境”，
删除任务成功后回到“工作区 → 新建环境 → Linux 沙箱”。需要保留的
文件先独立备份；删除环境也会清理本应用管理的该环境快照。

按当前实现，删除会撤销运行访问，移除 Linux VM 磁盘、所属浏览器
资料、环境配置及对应快照 / 导入 / 恢复目录。正常新建会分配新环境
编号，建立自己的磁盘和空白浏览器资料。Mac 共享项目文件、已经导出到
外部的备份文件、其他环境和网站服务端记录不会被这次删除清除。
这是应用层删除，不是对 SSD、系统备份或历史记录的安全擦除承诺。

重启保留旧资料；快照恢复 / 加密备份导入会带回保存的浏览器资料，
不能当作空白重置。删除重建不会自动更换实际公网线路，也不会把浏览器
版本、字体或图形环境变成一种全新设备。网站可以把多个浏览器 / 系统
特征组合用于识别，见 [MDN 指纹说明](https://developer.mozilla.org/en-US/docs/Glossary/Fingerprinting)。

因此只能承诺其限定的本地资料清理与隔离能力，不能承诺封号后无法
关联、解除服务端封禁或完全不被追踪。更换本地环境不会删除平台原有
的账户与登录记录。上述清理范围来自实现核对；不是实际账号封号后
重新使用的验证，本轮也不为验证它而删除用户现有环境。

## 不花 Claude 账号费用，先怎么试

可以先检查页面、运行环境、打开普通测试网页，在“终端”执行：

```sh
uname -s
date
printf 'MuCodeSandbox OK\n'
```

这些命令不需要 Claude 账号，也不会调用模型。安装 Claude Code 与
登录、调用模型是不同操作；初次熟悉后台可以先不安装它。

左侧“检测实验室”可以启动本地测试接收端、查看和下载检测报告。
0.4.1 优先显示“沙箱无账号检测”：选择已运行、启用强制防护和透明代理的
Linux 环境，点击“运行无账号检测”。它读取实际浏览器 / Worker / iframe
特征，做合成登录和本地模拟模型流，复核检测前后防护。报告按环境和时间
保存，可下载；不证明所有公网连接、DNS 或 WebRTC 都无泄漏。

“本机对照与原始接收端”单独折叠，其中“打开本机对照浏览器”会创建
本机浏览器环境，不是 Linux 沙箱浏览器；这条按钮的结果不能当成 VM
防泄漏验收。实验室页面绑定
Mac 的 `127.0.0.1`，不要把这个地址直接复制到 Linux 浏览器并期待能访问。
也不要把本机管理后台的授权链接复制进去。

官方 CLI 的无账号工具授权、流式任务等自动验收使用专用本地测试网关，
与日常“打开 Claude”不同；已有结果保存在验证文档中。无需为了熟悉
后台重新执行测试脚本。当前入口和验收范围见 [待办](TODO.md)。

“网络 → 线路设置向导”可以检查本机代理，并选择独立 Clash 节点。
选择独立节点时，本应用使用专用回环端口，不修改 Clash 的原全局选择。
线路随应用运行，退出后关闭，重新打开应用时恢复已保存选择。
节点名称不证明真实位置，启动后仍需点击“检测出口”。

## 文件共享与宿主授权的区别

“项目目录”像给虚拟机持续挂一个文件夹：只读不能改，读写会直接改 Mac
上的原文件。“宿主授权”是短期、有限的接口，不是把整个 Mac 交给虚拟机。

初次不需要二者同时配置。要试临时授权，可新建一个只含测试文件的
Mac 文件夹，环境启动后在“宿主授权”中选择它、选只读和 15 分钟，
点击“授权目录”。复制该授权的终端访问命令，在当前环境的“终端”执行。
试完点击撤销。Git 状态 / 差异 / 最近提交必须单独勾选，没有任意 Mac 命令执行权限。

## 快照与备份怎么用

1. 正常停止环境，确认没有进行中的任务和浏览器。
2. 进入“快照”，输入名称，点击“创建快照”。
3. 恢复时点击对应恢复按钮并确认：Linux 磁盘和配置会回到该时刻。
4. 要保存到独立文件，点击该快照的导出按钮，设置备份路径与密码。
5. 导入从“工作区”的“导入备份”进入，成功后得到一个新环境。

快照包含 Linux 浏览器资料，不包含 Mac 共享项目文件或旧本机浏览器资料。
加密备份需要自己保管密码；忘记密码无法靠管理后台恢复。
同机导入已验证，第二台 Mac 迁移仍未验收。

## 常见问题

| 现象 | 先做什么 |
| --- | --- |
| 页面一直显示连接失败 | 确认原应用 / 服务还在运行，使用当前启动入口重新打开；旧端口可能变化 |
| 创建成功但没有浏览器画面 | 创建配置不等于启动，先启动 Linux 环境，再从其“浏览器”页打开 |
| 启动很久 | 看“操作记录”和环境日志，区分下载、准备与真正报错；不要连续点启动 |
| 防护异常后自动停止 | 保留日志，检查线路和错误原因，修正后手动启动，不自动降级直连 |
| 网络设置不能修改 | 先停止环境并关闭相关浏览器，等待当前任务结束 |
| 没有住宅 IP | 应用不出售或生成住宅线路，需自行提供 |
| 看到 Linux / 软件 GPU | 当前真实运行环境就是 Linux，可能软件绘制，不是伪装失败 |
| macOS 提示应用签名问题 | 当前为临时签名本机测试包，正式发行签名 / 公证未完成；先保留完整提示，不关闭系统安全机制 |

当前尚未通过真实休眠、真实切网、全天稳定性、住宅公网和第二台设备
验收。Mac 其他应用不受这个 Linux 沙箱网络防护保护。完整边界见
[技术方案总览](technical-overview.md)，剩余工作见 [统一待办](TODO.md)。
