## 批准分发与独占安装

本轮批准组件为 [官方 npm Linux x64 分发 2.1.310](https://registry.npmjs.org/@anthropic-ai/claude-code-linux-x64/2.1.310)，发布文件为固定版本，不在安装时解析可变 latest。准备阶段实际核对注册表签名、SHA-512、归档大小与SHA-256，以及4份发行文件的长度/摘要、ELF64小端与x86-64类型。仅下载核验公开分发，未执行程序。

- 归档：131844169字节，SHA-256 `8c90b0170d08fdb370db282c61d74897b834fc2569dd14c35eb1e491212dc6de`。
- 原生程序：291638640字节，SHA-256 `b73676430af12f97316a798b8371f81d640f90a58bdcb8f3ce56a835bb47df56`。
- 固定客体目录：`/opt/mucodesandbox/windows/claude-code-2.1.310`；连同许可证、README、包元数据及安装摘要记录发布。

宿主只从固定地址获取组件并验证缓存身份与摘要；已有不明缓存不替换。客体流式接收和校验相同归档，再逐成员核对固定文件集合和摘要，不运行软件包脚本、不执行版本探测命令。安装使用root拥有且无组/其他用户写权限的逐级目录句柄、单硬链接普通文件、排他安装锁、空间余量检查与不覆盖目标的renameat2发布。暂存中断可在确认全部已有字节为相同批准内容前缀后继续写入；未知文件、改变内容、链接或不符权限保留并拒绝。发布后再次校验，完整版本可幂等重读，档案暂存被移除。程序和资料目录分开，项目及账号资料不作为安装或清理目标。

状态检测只读取组件文件，既不执行CLI也不检查登录账号。受信状态来自固定发行摘要与原目录/文件身份，未知组件不能靠自报版本取得信任。真实 Linux x64 CPU/ABI、权限、目录句柄、锁及发布行为尚待实机；普通 Windows 文件适配器证据不能替代这些检查。

## 任务、会话和终端

API沿用本机会话与Bearer认证、严格来源和请求体检查，安装要求完整当前环境名称及固定安装意图。客户端不能指定下载地址、组件路径、版本、命令或开启预览权限。管理器建立独立install-agent任务；安装失败、取消或迟到结果不会把已停止/出错环境改回运行。显式停止先取消任务，不等待大文件接收或校验；资源、电源、防护失败和退出继续撤销安装。当前Guest访问使用统一被动操作准入，防护核验仍单独执行。

一次性终端票据固定绑定shell或claude、当前防护会话与尺寸。升级连接时再次核验组件，票据发出后文件变化不能启动程序；重复票据、旧会话及无效来源继续拒绝。实际SSH构造方法固定dev用户、干净环境、/workspace目录及批准的CLI绝对路径，关闭SSH逃逸和本机命令/转发。CLI环境设置非必要流量、遥测、错误上报及自动更新相关禁用参数；本轮未执行CLI，不能据此声称验证了厂商参数的运行效果或账号隐私。网络访问仍由原客体防护与出口许可控制。

安装确认沿用通用模态窗口的焦点/键盘行为；完整名称、组合输入及单次提交边界检查通过。失败显示在当前确认窗口内，不能伪装成功；取消后读回实际状态。已核验组件不会因刷新或安装任务结束自动打开专用终端。
