固定候选为 `google-chrome-stable_156.0.8078.47-1_amd64.deb`，144849192 字节，SHA256 `6c92cd22e90c6e3e255d782991543fa2091db8614e8536a971a7433a5c4d7ac8`。已只读解析真实 DEB 的 control 资料，确认包名、版本和架构；Chrome 与 chrome-sandbox 均为 ELF64 AMD64。生产解包器和核验器另在普通宿主临时文件中处理同一真实包，核对全部254项文件及组件记录，没有执行厂商脚本或浏览器。DEB 解码命令由实际 ar/xz 数据流适配，Linux权限与setuid语义不属于该证据。

Chrome SHA256 为 `95dc9473b4f904cb3ab0800fc7206081fcae12abc094a088bd741a13f1747b72`；chrome-sandbox SHA256 为 `be9f5d4be90fa60b985ad3069812b144ba7331fed0c3f980c6d9399d37d60314`。共享解包/核验器为明确指定这些摘要的组件增加双重核对；旧组件没有新字段时保留既有归档和逐文件核验。

## 准备与接续

候选使用独立的版本目录和记录名称，复用既有双槽、身份绑定、前缀续传、独占发布与安装锁。候选仅能准备清单中的固定版本，调用方不能提供 URL、摘要或目标路径。初始化时目的目录已存在则拒绝覆盖；未完成或已完成的准备从原记录接续。当前组件的恢复事务尚未完成时，候选入口在创建工作目录前拒绝。

与当前组件恢复分别配置：候选不停止旧浏览器，不保留或替换已有目的组件，不修改选择记录和资料。发布后的已核验公开归档保留在原记录中，供后续接续及采用前完整核验。它有固定大小和现有保留代数上限；这不是可无限累积的下载缓存。后续采用/放弃流程仍需按原身份管理该归档，不能按前缀删除未知数据。

候选记录不会被旧组件恢复记录混用。未知文件、变化前缀、替换目录、硬链接、变化归档、损坏双槽或陌生目的目录均保留并拒绝。原组件、旧恢复记录、选择文件、网站资料和项目文件在验证中逐项核对保持。
