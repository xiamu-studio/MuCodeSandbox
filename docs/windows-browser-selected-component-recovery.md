## 读取与写入使用同一版本和事务

普通版本读取继续拒绝未完成修复。新的root只读观察仅允许检查自身修复目录，仍拒绝采用/重置/旧安装事务。按固定root目录、no-follow及有界描述符读取选择与修复双帧记录，核对批准的完整配方、root/slot/journal身份、所有权、权限、单链接与前后时间戳，拒绝重复JSON字段及未知目录内容。读取前后重新核对选择和记录。它不打开浏览器可执行文件或私有资料，因此损坏组件仍可按原批准配方恢复。

协调器先读取版本和未完成事务epoch，再关闭普通查看器、获取匹配归档，随后把所选批准版本及观测到的epoch或无事务状态钉入固定root程序。共同安装锁内再次检查：未完成事务出现、消失或epoch改变均拒绝；没有选择记录只授权初始155，不能据此修复156，且该拒绝发生在创建工作目录前。活动事务必须属于当前配方；扫描完成记录时，仅跳过已核验属于另一个批准配方的记录，不清理它的归档，损坏或未知配方仍保留并拒绝。

宿主归档加载沿用初始chrome.deb缓存，新版使用固定版本文件名；归档元数据来自应用批准清单，不接受请求中的URL、摘要或路径。已有大小、摘要、类型或链接数异常的缓存会保留并拒绝。读取后再次核对命名对象与打开文件的身份、大小、链接数和时间戳；预先取消或未知版本不创建缓存。结果回执及独立组件读回都必须精确匹配本次所选版本，不能用另一个已核验版本报告修复成功。环境配置摘要、原会话及取消状态贯穿异步步骤。
