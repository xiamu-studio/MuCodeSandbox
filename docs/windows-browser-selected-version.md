## 同一版本贯穿读取与启动

新的只读选择程序以相对no-follow、nonblock描述符检查固定root目录、限定4096字节的单链接root选择记录、精确字段和批准的版本/归档摘要，并复核路径和记录身份。没有选择记录时保留原初始版本；未知版本、重复字段、变化对象、活动采用/组件恢复标记均拒绝。没有按请求提供的路径或URL打开组件。

组件读取按此选择核验对应版本目录、原记录及完整可执行文件摘要；具有独立厂商摘要的候选再核对该摘要。资料观察以同一所选版本比较Last Version，读取结束前重新核对选择。一次组合观察的组件与资料必须对应同一选择，不能把两个时代的结果拼在一起。缺失记录仍明确显示未知，不作跨版本兼容证明。

新建浏览器会话时先读取选择，按其固定清单生成组件核验，再确认资料仍对应同一版本，准备显示并生成匹配的AppArmor路径、沙箱助手和dev启动命令。偏好写入前与最终执行前的资料程序都固定预期版本，选择变化就拒绝。初始页仍为空白，保存网址只由既有启动页规则在通过检查后处理。

CDP必须返回与选择完全一致的Chrome产品版本。沙箱检查使用对应可执行文件路径；运行中复核也再次读取选择，变化时不会借另一个版本的进程通过检查。已知选择错误直接失败，沿用原会话的独立停止收尾，不增加重试。取消或会话替换后的迟到读取不能继续准备或停止替代会话。

组件修复当前仍仅支持原155配方：选择不同版本时，root预检在组件写入前拒绝降级；最终读回也必须匹配本次修复版本，不能拿另一个已核验版本报告恢复成功。匹配新版的组件修复仍需后续实现。所有尚未验收的预览开关保持原值。

## 资料事务补强

检查点的普通文件mtime改用精确十进制纳秒PAX字段，宿主回退测试逐文件核对，消除浮点序列化丢失精度。开始采用前比较原资料、父目录与事务根的设备身份，跨文件系统在检查点发布前拒绝；尚未以真实Linux多文件系统验收。空间预留仍是归档大小加64MiB，实际块/ inode容量、配额及断电持久性未证明，不能承诺任意规模资料都能回退。

事务用例从48增至51，维持25次实际测试进程终止。提交与回退得到的选择和资料接入原读取算法；该组沿用合成DEB配方，因此明确适配其读取清单。另39个只读场景运行未经改写的实际批准清单和读取程序，使用真实文件/身份/硬链接；厂商候选二进制内容摘要仍为明确适配，没有重新下载或执行官方浏览器。
