# Windows 镜像缓存统计与回收

2026-10-21，Windows 预览增加系统页存储统计与受保护缓存回收。Mac 的虚拟化后端和发布流程保持独立。

## 规则

- 系统页显示镜像缓存、可清理文件、卷可用空间和已登记虚拟磁盘容量。镜像缓存继续使用现有 64 GiB 上限。
- 普通用户只能提交当前基盘摘要和已审阅计划的摘要，不能传入文件、目录、SID 或清理脚本。页面 API 自行选择当前基盘，使用已有 Cookie、Bearer 与同源校验。
- 当前基盘、所有受保护 VM 登记中的源镜像、构建器封存结果，以及实际 VM/检查点磁盘父子链仍引用的缓存均保留。当前基盘尚未发布时，封存目录中的基盘保留以供恢复。
- 清理限定于当前用户固定缓存目录中的已知镜像、封存登记和中断准备的临时文件。原 VM 磁盘及用户选定的原始镜像不参与回收。
- 每个计划绑定当前引用、文件身份、长度和最后写入时间；确认时重新核验，变化后要求重新检查。文件与目录的权限、重解析点和硬链接异常会拒绝继续。
- 同一进程的导入锁和跨进程导入锁串行保护回收、导入与封存。新分配先在同一锁下登记引用，已有磁盘转换期间仍有受保护引用。
- 未登记旧存储、未知缓存数据、系统组件准备中或依赖无法确认时，清理禁用。依赖查询读取本机 VM、检查点及挂载镜像元数据，拒绝远程磁盘路径和重解析点，不向页面返回其他 VM 的名称或路径。
- 封存登记先于其无引用镜像删除。中断的清理可以留下可再回收镜像，正在使用的登记与 VM 磁盘保持保留。

依赖查询使用 [Get-VMHardDiskDrive](https://learn.microsoft.com/en-us/powershell/module/hyper-v/get-vmharddiskdrive) 和 [Get-VHD](https://learn.microsoft.com/en-us/powershell/module/hyper-v/get-vhd)，包含实际检查点和父盘链。

## 隔离 Windows 实测

在网卡未接外部交换机的 Windows IoT LTSC 评估 VM 中，以普通用户和另一合成管理员完成真实 Linux/VHDX 场景。原 Linux VM 有 dev 写入的随机文件，业务联网许可关闭。

后端 11 项检查覆盖：真实运行 VM、实际快照专属父盘依赖、调用者路径拒绝、计划过期、独立进程持有导入锁、两个直接权限请求竞争、原 VM 文件保留、显式删除 VM/检查点后回收，以及保留基盘继续创建并启动新 Linux。当前盘与原始可复用镜像的摘要由独立管理员核对；两个原生测试 VM 和检查点对照机均最终移除。

页面/API 另有 7 项实测，使用普通用户的独立沙箱 Electron 测试壳加载生产页面和实际本机服务：

1. 生产权限代理与当前普通用户进程、源码绑定。
2. 临时给封存目录增加普通用户写权限后，拒绝检查/清理；独立管理员恢复原权限。
3. 页面显示真实缓存统计，渲染器没有 Node 访问。
4. 取消确认框不删除文件。
5. 确认框打开后实际增加缓存文件，旧计划被拒绝并显示提示。
6. 重新审阅后只清理合成临时副本，保留当前基盘。
7. 页面与服务正常关闭，无残留 VM 或外部网站访问。

页面实测发现统计刷新可能与自身清理竞争，现改为同一服务中顺序执行；等待查询后再次核验生命周期状态，外部进程的导入互斥继续保留。Windows 自动测试 113 项通过，包含缓存文件故障、API 边界与这些调度规则。

完整私有回执、截图与运行摘要保存在本机忽略目录；镜像、账号、密钥及实际机器资源清单不提交。测试只重启评估 VM，物理宿主启动标记和 Mac main 引用保持不变，没有访问 AI 网站。
