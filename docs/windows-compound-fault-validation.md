## 操作范围与收尾

管理员操作器只接受绑定实际普通用户进程、随机令牌、精确 VM GUID 和阶段序号的三个固定动作。停止服务前检查唯一内层 VM、受保护登记所有者、标记和原磁盘路径，并保持实际工作进程句柄。调用方不能指定服务名或填盘路径。

填盘量受物理宿主剩余空间上限约束。正常流程先释放磁盘压力，再恢复 VMMS；故障或超时收尾也会独立释放本次填盘文件、恢复自己停止的客体服务。运行中的旧进程不会因为观察超时而重复启动。回执在 Windows PowerShell 5 中原子替换。

收尾从受保护目录独立核对原生资源触发记录：会话标识对应本次运行，原因为 disk，实际空间低于生产底线。确认 VMMS 正常、压力文件消失、内层 VM 与登记为零、双副本一致、管理目录为空；控制器、代理和通道助手均已退出。

Pro 保持运行、网卡断开、合成自动登录关闭，保留后续人工桌面验收。物理宿主启动时间和 `main` 引用不变。8 个实际程序/资源文件与当前成品包和源码对应；本轮执行的 7 项相关自动回归及类型检查通过。没有修改产品阈值、权限代理或网络策略，也没有生成另一个发行版本。

私有汇总位于忽略文件 `.mu-data/windows-run/pro-compound-complete.json`，包含阶段回执、原生触发记录、文件绑定与原盘读回结果。账号、令牌、路径、日志及磁盘不提交。入口为 `scripts/windows-pro-compound.ts`、`scripts/windows-pro-probe.ts compound-*` 与 `scripts/windows-pro-compound-evidence.ts`。

真实物理网络切换、休眠/唤醒、长时负载、更多卷挂载与磁盘故障组合，以及历史资源迁移继续分别验收。本轮不代替这些项目，也不代表正式发布完成。
