2026-10-26 后台源码记录。源码为preview.45；实际安装preview.32和未安装候选preview.44保持。桌面操作暂停，本轮只用普通进程、临时文件和合成供应程序。

## 已处理

原生shutdown应答只表示接受请求，不能作为停机成功。工作进程原先按普通用户数据库中的配置逐个停止，可能遗漏原生登记中仍存在的环境；最后退出回退也逐个等待环境。现正常退出先取得并校验原生关闭回执，再关闭本地服务，最后轮询同一原生会话。只有全部受保护登记核验通过、写入计数和客体连接归零，才能发送stopped回执。错误回执、会话变化、读取失败、取消及超时均不能改成成功；正常关闭失败保留工作进程供重试。

原生关闭围栏不可撤销。拒绝新写入和客体连接，取消已有写入，排队的环境任务取得锁后再次核验准入。已经进入不能中断的磁盘事务可以收尾，其计数归零前不确认退出。每次轮询关闭连接，避免围栏建立前已进入的连接晚到后留下通道。

资源、电源、正常退出及所有者丢失共用32目标、最多4工作线程的核验队列。正常关闭仍在环境锁内调用原恢复核验；一个环境的锁或供应程序不能串行挡住其他目标。所有者丢失后不等待界面服务关闭，立即释放工作进程，由原生端继续固定身份的硬件停止回退。该回退不等待磁盘副本所持环境锁，不修改或采用供应程序返回的磁盘与登记；它只确认固定名称、平台标识及Off回执。不存在VM的部分创建登记也严格核验布尔值和空平台标识。

确认缓存同时绑定登记摘要与关闭阶段。已有写入全部收尾后重新核验，即使登记值未变，写入期间取得的“不存在”回执也不能复用。循环完成时再次比对当前目标，任何晚到创建或登记变化仍保持未确认。原生最后回退设置五分钟轮询期限，超时或未加载登记不报成功，并记录shutdown-state.json；系统或全局磁盘I/O卡住本身尚不由该期限证明。准备会话存在登记时不能声称VM已停，恢复会话关闭只代表其只读会话结束，不能用来证明不可信VM停机。
