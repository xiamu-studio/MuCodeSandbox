# Windows 磁盘扩容

Windows 预览版 `0.4.66-preview.6` 增加受保护的磁盘维护入口。隔离 Pro 与真实 Linux 的原盘扩容、取消和控制进程强退恢复专项已通过，其他卷布局及电源故障继续单独覆盖。

## 操作边界

环境必须停止并确认原 VM、磁盘路径、VHDX 标识和 NTFS 文件身份。只支持独立动态 VHDX、当前 Linux 基盘的 `/dev/sda1` ext4 根分区和 16–256 GiB 容量；拒绝缩容、基盘构建器、检查点、父子盘、共享盘、硬链接、身份不明及跨出保护目录的资源。用户先核对容量，再输入完整环境名称确认。

虚拟盘在 Off 状态扩大。当前 Hyper-V 使用 IDE 控制器，微软也要求 IDE 链上的虚拟盘离线调整，参见 [Resize-VHD](https://learn.microsoft.com/powershell/module/hyper-v/resize-vhd)。文件系统在维护启动中扩展，完成后确认停机，环境保持停止。

维护先只读核对根分区与工具，再修改虚拟盘。每次维护启动都在 `/run` 的 tmpfs 中建立新的关闭许可状态，清空内核许可集合并复用完整防护核验；不建立业务转发、不打开联网许可。许可规则和助手文件须符合当前固定摘要。文件系统操作的临时文件也放在内存目录，避免依赖根分区剩余空间。

根分区的真实起点、分区大小和 ext4 块容量分别核对，分区与文件系统都必须到达允许的末端误差内。支持启动区占用 1–2048 MiB，不能把启动分区所占空间误判为未扩容，也不能用两者大小一致掩盖未使用的磁盘尾部。扩展过程保持根分区起点不变。

## 中断与容量登记

受保护登记在 VHDX 修改前持久化原容量、目标容量、VHDX 标识和 NTFS 文件身份，并先保存两份登记副本。目标容量立即计入当前用户的 1 TiB 总预留；扩容同时重新核对实际卷的动态增长需求和宿主空间底线。

取消或进程退出后不缩回磁盘。未完成记录阻止普通业务启动，只允许继续原目标。文件系统容量、原盘身份和实际停机均确认后，才清除记录并更新工作区容量；若原生提交后工作区更新中断，可核对已提交容量并同步记录，无需再启动维护。

## 当前证据与后续

Windows 本地回归通过 205 项（并发数 4）。检查覆盖容量与文件身份、登记副本中断、未知字段与非法标识、API 来源与确认、维护期间关闭业务、取消及恢复、容量记录同步。一次默认并发运行的音频文件级失败保留在本机；该文件单独复核与并发 4 的完整回归均通过，没有修改音频实现或放宽断言。

界面专项通过 8 项，包括确认名称、候选输入及键码 229 不提交、固定恢复目标、上限、窄屏、错误和取消只读核查。报告记录组件源码摘要；合成 composition 事件不计为真实 Windows 输入法验收。

真实专项使用隔离 Pro 内两台 Linux VM，完成 12 项客户端检查及一次独立控制进程强退观察：

- 原盘由 32 GiB 扩至 40 GiB，核对 ext4 实际容量、原 VM/VHDX 身份及 dev 用户的中文文件样本；运行中请求、缩容、越界容量和调用者路径拒绝。
- 实际受保护预留达到 1 TiB 后拒绝进一步扩大原盘；移除本轮失败预留后继续。生产阈值未被替换。
- 在 VHDX 已扩大到 48 GiB、文件系统完成状态尚未提交时取消，业务启动继续拒绝。管理员观察程序核对原盘及登记后，按已持有的进程句柄强退指定控制器，并等待独立代理实际退出。
- 新普通用户进程与新代理恢复同一原盘和待完成记录，完成 48 GiB 文件系统核验；再在文件系统已扩到 56 GiB、工作区尚未提交时取消，继续相同目标并读回原文件。
- 独立对照环境的 32 GiB 容量、身份及文件样本保持，最终仍可启动；完成后删除本轮两台停止的 VM 和专属资源。

维护期间内核联网许可保持关闭，本地业务接收端及 DNS 请求计数不增长。这不代替物理切网、休眠及逐包专项。实机执行的 6 个后端文件与当前包、编译产物绑定，保护代理源码摘要也与包内原生源码一致；源镜像整体 SHA-256 保持不变。

独立收尾确认内层 VM、专属交换机、受保护登记双副本和运行目录均为零，控制器及代理已退出。Pro 测试机保留运行供手动登录，网卡断开、自动登录关闭。物理宿主启动时间和远端 Mac `main` 引用保持不变，未访问 AI 网站。

未签名 NSIS 包构建与审计通过：5635 个文件，167 个代码文件与暂存载荷一致，本轮本机路径及运行私密文件发现数为零。命令 `node scripts/windows-pro-disk-evidence.ts` 可复核本机受限证据索引；VM、密钥、账号、报告及截图不提交 Git。

Mac 的 VZ/Lima 磁盘实现、Swift、桌面入口及发布流程保持独立。真实断电、更多卷布局、快照、加密备份和 Mac 实机回归仍在 [完整清单](windows-work-plan.md) 中。
