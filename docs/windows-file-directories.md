# Windows 新建文件夹

源码已接入 Windows 文件面板和受保护客体通道，并从未签名 `preview.9` 测试包提供；`preview.8` 既有安装包没有此功能。真实 Linux 的创建、权限、路径与绑定挂载边界前置检查已通过。第二轮因 SSH 诊断混入数据而停止，失败原盘保留；`preview.10` 修复传输层，重新进行整轮持续运行、重启读回及收尾。

## 行为和权限

文件面板可在下载、传入、导出目录及其子目录创建文件夹。名称保留中文、emoji、空格和引号，限制为 180 个 UTF-8 字节、最多 16 层及 2048 字节路径；拒绝路径分隔符、控制字符、不完整 Unicode，以及列表中不可见的隐藏或临时名称。已有同名条目返回冲突，不覆盖，也不自动重试。

固定 Python 程序和请求数据通过 stdin 分开发送，使用客体 `dev` 身份。沿目录句柄调用 `openat2`，限制在所选目录下，拒绝符号链接、魔术链接和跨挂载解析，包括绑定挂载；每个客体目录还需由 `dev` 拥有。接口依据 [Linux openat2 说明](https://man7.org/linux/man-pages/man2/openat2.2.html)、[内核标志定义](https://raw.githubusercontent.com/torvalds/linux/master/include/uapi/linux/openat2.h) 和 [AMD64 系统调用表](https://raw.githubusercontent.com/torvalds/linux/master/arch/x86/entry/syscalls/syscall_64.tbl) 实现。内核或架构不支持时拒绝，不降级为较弱的路径解析。

成功创建后同步新目录和父目录，并重新核对目录身份。取消、路径变化或结果无法确认时保留可能已创建的目录，让用户刷新确认；不做推测性删除。复用文件交换互斥、原会话绑定及防护撤销信号，HTTP 调用断开也取消客体工作。宿主文件路径和管理权限不是此接口的输入。

文件面板以独立请求上下文关联列表、下载和创建结果；切换环境或目录、取消上传后，旧上下文的迟到响应不能改变新界面或触发本机下载。创建过程中候选输入不提交，失败保留名称，重试需要再次明确操作。旧服务没有 `fileDirectories` 能力时隐藏创建入口。

## 已验证与待验证

7 项单元/API 检查通过：名称与层级边界、固定命令与 stdin、普通身份、共享互斥、既有条目与不确定结果、取消、会话变化，以及实际 Windows 本机 API 的 Cookie/Bearer/Origin、断开与旧会话拒绝。

Playwright CLI 使用产品组件、实际 Windows 样式和本机合成 API 完成 8 项界面检查，覆盖候选事件、UTF-8、嵌套创建、冲突后草稿、迟到列表、迟到下载、迟到创建结果、能力隐藏及窄屏。没有真实操作系统输入法事件、Linux 文件操作或宿主文件下载，不能混算为这些实测通过。

最初源码阶段的 218 项 Windows 自动测试和类型检查通过；随后 `preview.9` 全套 222 项通过，原 `preview.8` 载荷另行保留。真实 Pro/Linux 的 HTTP 创建成功核对中文、emoji、引号与 shell 符号名称、dev UID 2001 和 0700 权限、嵌套创建及同名拒绝；符号链接、同文件系统绑定挂载及可写的其他所有者目录都拒绝创建，外部目标没有出现请求目录。真实层级接受 16 层，拒绝 17 层；完成写入后延迟确认，再取消请求，目录保留且互斥解除。

这些前置检查使用实际 Linux 程序，诊断延迟只确定取消时点。它们不等于 Windows 原生输入法、完整安装向导或 GUI 交互通过。所在持续运行案例还需完成整个时长、原盘重启读回及资源清理。重命名、删除等其余文件操作继续单独开发；Mac 服务、Lima/VZ、Swift、桌面及发布架构保持不变。
