# Windows 沙箱文件管理器入口

`preview.11` 接通与 Mac 相同的客体 Thunar 文件管理器，在现有沙箱画面内打开目录。真实 Pro/Linux 的窗口、重命名、移动、删除及关闭回收已通过独立验收；`preview.10` 不包含此入口。

## 使用方式

先在软件中打开浏览器画面，再到文件面板选择下载、传入或导出目录，点击“在沙箱中打开文件夹”。收到成功回执后切换至沙箱画面。文件操作在 Linux 内完成，不启动 Windows 资源管理器，不要求进入外层 Windows 测试机桌面。

旧服务没有 `fileManager` 能力时隐藏入口；画面尚未就绪时禁用并提示。切换环境或目录后，迟到回执不能把新界面切走。接口只接受受限的 `zone/path`，拒绝宿主路径和项目共享标识，Windows 持续共享仍未开放。

## 边界与取消

沿用共享 `GuestExchange.openFolder`，不改动 Mac 实现。启动进程固定为客体 `dev` 用户与组，清空继承环境，使用固定 Thunar 路径和独立 systemd 单元；单元绑定图形服务，停止客体图形服务或 VM 后随之回收。仅隐藏或切换软件画面不等于停止服务。路径解析继续使用客体目录句柄及链接检查，文件管理器保留普通 Linux 用户权限。

Windows 服务复用文件传输互斥、原会话绑定、全局在途上限和防护撤销。请求断开会取消启动链路，原会话停止或重启后，迟到的第一步结果不能继续在新会话执行后续启动命令；已打开的客体窗口不做推测性撤销或文件删除。

## 检查范围

新增真实 Windows 本机 API 的合成后端回归，通过 Cookie/Bearer/Origin、画面前置条件、未知字段拒绝、固定 dev/systemd 参数、HTTP 断开取消及跨重启迟到启动拒绝。没有启动真实图形程序，不能计作 Linux GUI 验收。

Playwright CLI 的 5 项产品组件检查通过：画面要求、明确打开、子目录路径、迟到确认不切换新环境、能力隐藏与窄屏。原有 8 项目录创建界面检查也通过，Windows 全套源码自动检查 228 项通过。本轮仅使用本机合成 API，没有操作宿主文件管理器或访问 AI 网站。

## preview.11 真实图形验收

使用审计后的未签名 `preview.11` 包载荷，普通 Pro 用户启动真实受保护 Linux、空白 Chrome 画面及沙箱化产品渲染器。节点集成关闭、上下文隔离和渲染器沙箱均实际核对；页面不能使用 `window.require`。诊断主入口拒绝所有宿主剪贴板 IPC 和权限请求，不使用外层 Windows 桌面认证。

通过实际产品文件面板选中专属合成目录，点击“在沙箱中打开文件夹”，确认软件切到 VNC 画面且 Linux Thunar 窗口显示该目录。客体进程以 `dev` UID 2001 运行。关键界面转换处读取实际截图，每步保存画面与文件系统结果；18 个受限步骤只通过产品 VNC 查看器发送鼠标与键盘，命令只能选择固定测试文件名、目录和已允许的按键，出现认证标题则停止。

实际完成三项操作：

- 重命名 `a-rename.txt`，核对旧名称消失、新文件内容仍为原合成文字。
- 在界面剪切 `b-move.txt`、进入 `target` 并粘贴，核对源文件消失、目标内容保持一致。没有读取 Windows 剪贴板。
- 选中 `c-delete.txt` 并在永久删除确认框中确认，核对文件消失。本轮不是回收站或撤销功能验收，不对数据恢复能力作保证。

关闭产品的客体图形服务后，Thunar 进程归零；随后确认原 VM Off，删除其专属分配。独立核查确认控制器和代理退出、VM/交换机/登记/运行目录为零，登记副本相同。

共 6 项真实检查、18 个界面步骤通过。8 个实际后端文件和全部 30 个前端文件与包载荷、本地编译产物逐项摘要匹配，诊断主入口与客户端源码也绑定。安装包审计 5638 个文件、170 个代码文件，未发现本机路径或运行私密数据。物理宿主启动时间及远端 `main` 不变；没有访问 AI 网站、外部翻译服务或真实账号。

观察进度时曾遇到读取句柄与原子发布冲突。该步已在 Linux 执行并经后续序号及文件系统观察确认，没有重发按键；观察端改为共享读写/删除句柄，不阻止客户端原子替换进度。失败观察回执保留，不算界面动作失败或重复操作。

准备与复核入口为 `scripts/windows-pro-filemanager.ts`、`windows-pro-probe.ts` 的 `filemanager-stage/run/inspect/step`、受限 `scripts/windows-pro-filemanager-step.ts`，以及清理后的 `scripts/windows-pro-filemanager-evidence.ts`。已有案例禁止覆盖或重启。本轮没有执行 NSIS 图形安装向导、原生 Windows 输入法或真实系统文件操作；这些待办继续单独验收。
