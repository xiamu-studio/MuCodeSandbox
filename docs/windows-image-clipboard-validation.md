# Windows 图片剪贴板验收

2026-10-22，Windows 预览版 0.4.66-preview.2 增加图片按钮和图片粘贴区。点击“粘贴图片到沙箱”，或在图片粘贴区按 Ctrl+V，将图片放入 Linux 临时剪贴板，再在客体画面中按 Ctrl+V。单张上限 10 MiB、1600 万像素。

Windows 使用独立 preload 和 IPC 名称，复用现有 PNG 校验、Electron 图片解码及 Linux 剪贴板服务；Mac 桌面入口和共享实现保持原样。读取采用 [Electron 44 的异步 ClipboardItem 接口](https://www.electronjs.org/docs/latest/api/clipboard)，选取 PNG 数据，文件列表和普通文本不作为图片传输内容。

## 实际链路

在网卡断开的独立 Pro 测试 VM 内，以合成普通用户运行当前打包的界面、Windows preload、图片读取处理器及正常权限代理。Electron 测试窗口使用真实 Windows 系统剪贴板中的合成图片，内层 Linux 使用真实图形基盘和本地 HTTPS 页面。

| 检查 | 已验证结果 |
| --- | --- |
| 1 | 普通用户连接受保护代理，代理与当前打包的原生源摘要一致 |
| 2 | 真实 AMD64 Linux 浏览器打开本地 HTTPS 页面，渲染器和 GPU 沙箱通过核验 |
| 3 | 隔离世界确认没有用户激活后，页面伪造主世界激活属性仍不能读取系统剪贴板 |
| 4 | 实际点击图片按钮，只取出 PNG，并由生产界面收到客体确认 |
| 5 | Linux X 剪贴板读回与桌面处理器输出逐字节一致，临时目录只有图片套接字，没有图片文件 |
| 6 | 通过实际 Windows 查看器点击客体输入框、等待焦点回执后按 Ctrl+V，Linux 页面收到可信粘贴事件，尺寸及透明像素与 2×2 源图一致 |
| 7 | Windows 图片粘贴区的真实 Ctrl+V 传入另一张 3×2 图片；Linux 查看器再次粘贴得到新尺寸和像素，没有多调一次原生读取 IPC |
| 8 | 产品关闭显示后图片套接字消失，实例服务通过 BindsTo/PartOf 与显示绑定 |
| 9 | 产品确认 VM Off 后删除本次专属 VM、交换机及磁盘；独立收尾确认登记双副本一致且为空 |

测试不读取物理宿主剪贴板。代理只映射保留测试地址到回环接收端，未访问 AI 网站或真实账号。测试窗口加载当前产品界面及图片模块；正常安装桌面主入口的首次系统认证继续列在安装专项待办。

## 请求和读取边界

原生读取限定在已聚焦的普通工作区主窗口、对应本机服务来源及真实用户激活。激活从隔离世界读取，异步过程持续核对来源和导航代次；恢复模式、后台窗口、子框架或已失效请求不能交付图片。

HTTP 接口同时核验启动 Cookie、Bearer、Host、Origin、有效业务许可和请求开始时的联网会话。读取体积、读取时间及并发均有限制；图片经完整 PNG 校验后才进入客体。请求取消或防护撤销会取消当前客体命令，会话变化后的结果不再交付。

Windows 自动测试 164 项通过，包含图片来源、手势、异步失效、非法输入、读取期间更换会话、请求取消和保留资源重试边界。共享图片模块 5 项回归通过；这些结果不替代 Mac 实机回归。

负向验收曾使用 Playwright 的页面求值，驱动会附带用户手势，污染了“没有用户激活”的前提。失败轮次完整保留；修正为等待激活到期，再通过主进程明确指定 userGesture=false，核对隔离世界确实未激活后执行。查看器输入还须等待真实客体焦点回执，焦点未确认时不计为粘贴成功。每次重试都先确认原客户端终止、原 VM 停止及登记/磁盘身份一致，保留失败报告并复用原盘。

## 构建和收尾

已生成独立的未签名 0.4.66-preview.2 NSIS 包，Mac 版本号仍为 0.4.65。实际 Pro 中的前后端 40 个文件与当前源码重新编译的结果一致；安装包的应用资源目录共核对 5626 个文件，其中 159 个代码文件与暂存源一致，未发现本机用户路径标记或私有运行文件。

本机忽略文件 .mu-data/windows-run/pro-image-complete.json、image-package-audit.json、image-tests.txt 和 image-shared-tests.txt 保存分项证据。账号、密钥、令牌、磁盘、截图、个人路径及运行回执不提交。

独立收尾确认内层 VM、专属交换机、受保护登记及运行目录均为零，VMMS 已恢复就绪；合成自动登录关闭，外层 Pro 测试机 Off。物理宿主启动时间、Mac main 引用保持不变。实际切网和休眠、音频、真实输入法、翻译浮窗、安装版首次认证及发布回归仍按 [Windows 工作清单](windows-work-plan.md) 继续。
