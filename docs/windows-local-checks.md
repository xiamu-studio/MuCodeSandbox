## preview.45 本机检测对照（后台源码，真实桌面验收未完成）

参照Mac29/62实验室页面，在Windows高级区域补上启动/停止本机接收端、打开独立对照窗口、本机地址、DNS/STUN端口、事件/模拟调用数及原始报告。Linux沙箱报告仍独立读取，宿主读数不会成为Linux防护通过凭据。本功能是本机合成检测对照；一般本机浏览器环境模式、真实网站和账号使用仍未交付。

接收端仅绑定IPv4回环。为共用createAcceptanceLab增加可选的私有capability和runId：Windows每轮生成64位十六进制随机路径，缺失/错误路径拒绝，HTML/模块Worker/iframe/Fetch和HttpOnly Cookie路径均绑定该轮。禁止添加客体转发来源；原Mac默认参数、URL、Cookie路径和行为保持。HTTP主机/Origin核验、消息输入边界、拒绝真实凭据、最多100份接收记录/1000条事件等原有约束继续生效。DNS/STUN是本地接收端，不改变系统DNS，也不证明公网DNS/WebRTC泄漏边界。

Windows管理API继续使用实际UI Cookie、Bearer和Origin校验；启动只接受空对象，停止和开窗要求准确runId。启动合并同一次并发请求，初始化中停止会等待并关闭原接收端；旧run不能停止替换后的新run。关闭失败保留running/error状态和原端口资料，可显式重试，不伪装已停止。服务退出仍先保证原VM管理收尾，并独立等待本机端口关闭。本机启动/停止不创建环境或调用VM操作。

每个服务进程生成独立窗口签名密钥，只经已验证PID的子进程IPC交给主进程，恢复模式拒收；HTML/public状态不含密钥。窗口描述绑定应用Origin、runId、精确127.0.0.1地址和10秒时限，HMAC核验拒绝修改、未知字段、错误宿主、外部地址和过期回执。打开窗口需来自当前主框架、当前窗口与世代，并核对实际用户手势；后续异步边界重新验证原会话。
