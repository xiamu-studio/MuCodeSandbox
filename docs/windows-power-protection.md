# Windows 原生电源与传输连续性防护

Windows 分支增加独立原生电源通知、时钟连续性及传输控制心跳。2026-10-22，专用 Windows 评估 VM 中完成真实防护进程暂停和原盘恢复验收；Mac 后端和发布入口保持独立。

## 运行行为

- 代理和每个 Hyper-V socket 传输进程分别订阅 Windows 电源通知。休眠或唤醒通知关闭当前运行代次；注册失败时不提供可用的传输或 VM 启动权限。
- 每个原生进程使用独立线程核验连续性，数据双向转发前也重新检查。监测间隔超过 5 秒、运行时钟回退、墙上时钟与运行时钟偏差超过 2 秒，或无法取得可信采样时，旧连接关闭；休眠时间偏差超过 100 毫秒同样关闭旧代次。直接电源通知不受该时间偏差阈值限制。
- 时钟采样使用 `GetTickCount64` 和 `QueryUnbiasedInterruptTimePrecise`。前者计入休眠时间，后者只计入工作时间；当前验收构建从 `KernelBase.dll` 绑定后者的导出。采样本身跨越过长时间时也拒绝。参考 [Windows 运行时间](https://learn.microsoft.com/en-us/windows/win32/sysinfo/windows-time) 和 [精确 unbiased interrupt time](https://learn.microsoft.com/en-us/windows/win32/api/realtimeapiset/nf-realtimeapiset-queryunbiasedinterrupttimeprecise)。
- 控制方每 500 毫秒向专属传输的 stdin 发送并刷新一个固定心跳字节。传输须先收到有效控制心跳才开放监听，超过 2.5 秒未收到续发时关闭 listener 与现有连接。心跳只表示控制方进展，不修改客体联网许可；未知字节拒绝。发送使用专门线程，避免缓冲或线程池拥塞被误当作已送达。
- 电源代次关闭后，原生层取消创建、增长和启动操作，关闭传输并反复核验当前用户已登记 VM 为 Off。停止、状态查询及可安全执行的删除/缓存回收保留；旧代次不能重新启动或打开通道。恢复登记的发布也需要有效电源代次。
- 停机尚未确认与已确认 Off 分别呈现。普通管理器撤销终端、浏览器和传输访问，并显示独立电源原因；不会把它作为磁盘/内存不足显示。重新打开软件建立新代次后仍需重新进行网络核验。
- 代理会话文件锁由操作系统在整个进程退出后释放，避免后台清理与下一代理交叠。电源监测不修改系统电源计划，也不主动让电脑进入任何电源状态。

电源通知使用 [PowerRegisterSuspendResumeNotification](https://learn.microsoft.com/en-us/windows/win32/api/powerbase/nf-powerbase-powerregistersuspendresumenotification)，处理 suspend、resume suspend 和 resume automatic，并在退出时取消订阅。通知、采样、检查阈值和心跳格式不接受 IPC 调整；只读电源接口仍绑定原进程与 SID。

## 验收范围

先在空白、网卡断开的评估 Windows 中运行 `powercfg /a`。其固件报告 S1/S2/S3、S0 Low Power Idle 和 S4 均不可用，S4 原因为固件不支持。查询后确认外层 VM Off，没有更改电源设置。

本轮覆盖电源通知订阅、回调语义、时钟连续性和真实组件暂停。实际 S3/S4/S0 进入与唤醒、对应逐包观测，以及物理网络切换继续保留为完整验收项目，需使用支持相应状态的机器。

| 阶段 | 操作与结果 | 检查数 |
| --- | --- | --- |
| 原生进程真实暂停 | 普通用户创建/启动嵌套 Linux，两个本地 TLS 接收端验证许可；写入 dev canary；持续新 HTTPS 请求与既有流均活跃后，独立管理员仅暂停绑定代理的原始线程 8 秒；控制器和本地接收端继续运行，心跳断开后新旧业务路径停止；恢复后确认原 VM Off，原生/应用两层拒绝旧代次重启 | 7 |
| 新代次恢复 | 新代理保持原 GUID，新启动读回原 canary，客体业务许可保持关闭；确认停止后清理合成 VM/磁盘/交换机 | 4 |

共 11 项通过。暂停前逐一核验受保护可执行文件、原进程/普通用户 owner/nonce、专用测试 VM、对应磁盘和线程所属进程；每个暂停句柄均在 `finally` 恢复或确认原线程已退出。演练没有提供产品级进程暂停接口，也未注入原生电源事件来替代该真实暂停。

Windows 自动测试 136 项通过，覆盖原生时钟边界、实际通知注册与取消、回调语义注入、控制进程仍存活但停止心跳时的真实传输退出、应用层电源关闭传播、权限接口及原有 Windows 回归。内核通知的语义注入只在独立测试对象中执行，不代表系统实际休眠。

私有报告由忽略文件 `.mu-data/windows-run/clean-host-power-complete.json` 指向；原生代码、构建脚本和实际管理模块摘要对应当前实现。独立管理员最终确认登记副本一致且为空、嵌套 VM 为零、关闭合成自动登录并确认外层 VM Off。没有重启物理宿主、改变宿主电源或网络设置、访问 AI 网站。初轮心跳缓冲与诊断对象选择失败记录保留在本机，没有计入通过。
