# Windows 11 Pro 独立环境验收

2026-10-22，在独立的简体中文 Windows 11 Pro 26300.9457 x64 客体中完成组件准备和嵌套 Linux 核心链路。使用合成本地普通用户及另一个管理员账号；应用用户不属于 Administrators。外层测试 VM 为 Gen2、Secure Boot 开启、虚拟 TPM 开启、4 CPU、静态 10 GiB 内存和专用 160 GiB 动态磁盘，网卡未连接交换机。

OpenSSH 客户端由该微软 Pro 镜像预装。本轮不计为缺失 OpenSSH 安装；该场景的实际移除、失败关闭与 FoD 安装证据仍单独保留在 [OpenSSH 验收](windows-openssh-validation.md)。

收尾由独立管理员会话直接查询 Hyper-V 和受保护目录：内层 VM、专属交换机、登记记录和运行目录均为零，登记双副本字节一致。确认保护代理源摘要与当前产品源一致，停用合成自动登录后关闭外层 Pro VM；另行核验其 Off、VHDX 未附着、Secure Boot/TPM 保留、网卡断开、物理宿主启动时间及 Mac main 引用不变。

本机忽略文件 .mu-data/windows-run/pro-host-complete.json 指向各阶段私有回执。磁盘、账号、应答文件、日志和控制台图像均不提交。Windows 自动测试共 156 项，其中 7 项覆盖新增部署输入、磁盘、EFI 文件名、无外部依赖的标记检查及重启连接等待。

## 部署边界与实测修复

微软多版本镜像的官方摘要及 Pro 索引 4 已先完成校验，来源见 [安装兼容性进展](windows-install-compatibility.md)。映像仅应用到新建、独立、精确容量且非宿主启动/系统盘的 VHDX。测试载荷以原普通用户令牌打开，拒绝链接，读取期间持有禁止替换的文件句柄；管理员仅将这些输入复制到本次专用磁盘。

宿主 DISM 挂载 WinPE 时返回文件访问错误。改为普通用户用 [wimlib 官方 Windows 工具](https://wimlib.net/)更新独立的启动映像副本并执行完整校验，再生成测试专用 ISO；不修改原始微软 ISO，也不运行宿主 BCD 修复。wimlib 1.14.5 工具只保存在本机诊断缓存，不作为产品依赖分发。工具摘要来自对作者 HTTPS 发布文件的本地记录，不冒充作者另行发布的校验清单。

派生 ISO 的主文件系统最初将 MICROSOFT 截成 MICROS~1，导致 EFI 找不到 BCD。生成器改用支持长文件名的 ISO 兼容级别和 UDF；回归直接解析主目录记录，而非只检查文件能否由归档工具列出。WinPE 也未包含 findstr，部署标记检查已改为内置命令，并直接验证实际标记匹配函数对正确、错误、缺失文件的行为。

Hyper-V 对用户目录中的派生 DVD 附件报告路径不可用；改用管理员保护的 ProgramData 专用副本后附加成功。副本只授予本次 VM 的专属身份读取权限。重试保留原 VM、原 VHDX 及 TPM 身份，不重设已初始化的安全启动模板。

Pro 重启时曾提前连回旧 Windows 会话，后续构建落在系统切换窗口。连接器现在必须读取到不同的启动标记，才把重启当作完成；模拟旧会话的回归及实际空载 Pro 重启均已验证。

## 仍待验收

本轮覆盖的是打包后端在 Pro 中的组件安装与嵌套 Linux 核心流程。Pro 上的完整 NSIS/图形基盘准备、UAC 交互、控制面板条目及 GUI 卸载仍待补测；物理宿主此前控制面板筛选未显示条目的原因尚未确定，工具拦截卸载器启动也没有计为通过。

本轮没有访问 AI 网站、进行真实账号测试或修改 Mac 的 Lima/VZ、Swift、桌面入口及发布流程。音频、真实输入法、图片剪贴板、真实休眠/唤醒、进阶网络模式和正式发布回归继续保持独立待办。
