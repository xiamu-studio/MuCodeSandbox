## preview.28 实现及 preview.29 修正

Windows 会话在发现错误时先发起断网和停机，再同步保存有界诊断；不等待停机完成才记录原始错误。记录包括检测端、状态、连接阶段、命令耗时及请求/确认/失败的停机结果。保存失败时保留内存记录并提示下载，不阻挡停机。记录清理 URL、凭证和原始回执标记；诊断仍可能包含出口 IP，应作为本机资料处理。

启动恢复只在独立运行时确认 Off 后补记此前尚待确认的停机请求；不能把旧版缺失记录或过去失败改写成当时成功。正常退出不新增故障。仅当前正常启动完成、至少两个已知独立检测端回执与批准 IP 一致且有实际耗时，才为旧记录附加本次恢复结果，原始 checks 保持原值。curl(56) 即使另两个检测端成功也仍触发保护，不改为普通超时放行。
