## 实际问题与修复

当前宿主在已安装 preview.18 的真实界面发起 Linux 组件准备后，官方归档校验与提取成功，创建临时构建器时由受保护资源准入拒绝。底层错误是 `RESOURCE_DISK`：同卷动态盘的增长预留与本次创建需求超过可用空间。原界面只显示“Linux 组件准备未完成，可重试”，退出后还会把具体原因替换为“上次准备未完成”，无法帮助用户判断重试是否有用。

preview.19 将权限代理的六种已知资源错误映射为固定中文提示，分别说明磁盘增长预留、宿主内存预留、用户容量上限、资源保护已关闭会话、其他启动操作和其他镜像操作。提示引导用户检查存储、释放资源、等待操作或重新打开软件。未知错误仍使用通用提示，不把异常原文、路径或凭据写入界面和准备日志。

准备日志保持版本 1，新增可选、枚举校验的 `failureCode`；旧日志仍可读取。已结束且清理成功的资源失败在重开后保留安全提示，新重试会清除旧原因，成功完成后不再保存该代码。取消保持取消提示；构建器清理未确认时优先显示清理问题并保留构建器，不用原始资源原因掩盖它。磁盘、内存和容量保护未被放宽。
