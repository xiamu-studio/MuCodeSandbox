# Windows 翻译浮窗与快捷键

Windows 预览版 `0.4.66-preview.5` 接入中文输入与翻译浮窗。浏览器和终端可使用 `Ctrl+Shift+Y` 展开或收起，`Ctrl+Enter` 仅粘贴当前原文或译文。候选输入期间不触发这两个快捷键，关闭后保留草稿。

## 调用与存储

- 只有明确点击翻译或“取回并翻译”才发送文字；保存和删除 Key 不进行测试请求。终端取回只读取当前选择，不读取 Linux 或 Windows 剪贴板。
- Windows 设置独立保存在受限工作区的加密文件中，使用当前用户 DPAPI 保护的应用密钥；接口只返回配置状态。拒绝未知格式、硬链接和替换的数据目录。Mac 的权限检查和密钥文件实现保持原样。
- 翻译复用客体内的固定 Python/curl 协议。Key、原文及请求体只通过受保护客体通道的 stdin 传入，不加入命令行、日志或环境配置；不提供自定义端点、宿主直连、重定向或自动重试。
- HTTP 连接断开、Key 变化、环境会话撤销和服务关闭均取消在途请求；旧会话结果不交付。查看器只有在原画面和浮窗仍有效时才发送粘贴键，并释放 Control。
- Windows 桌面文字剪贴板接口限定当前正常模式、聚焦窗口、主框架、同源首页及隔离世界中的真实用户激活。只读取或写入普通文字，不检查图片、文件列表或其他格式；异步完成后再次核对导航和模式代次。

## 已完成的本地检查

`npm run test:windows` 通过 188 项。新增设置及接口检查覆盖加密保存与重开、未知/链接文件保留、鉴权、来源校验、字数限制、显式调用、错误脱敏、取消、并发、Key 变化及无自动重试。文字剪贴板检查覆盖来源/用户激活、异步失效、长度与空字符限制。

`node scripts/verify-windows-text-input.ts --translation` 通过 19 项界面检查，包含原有 11 项输入保护和 8 项 Windows 工具检查。使用实际产品组件、合成 VNC/终端接收端及合成剪贴板桥；验证打开不读取、不翻译，候选/修饰键保护、显式翻译、修改后粘贴、收起取消与保留、取回方向、放大阅读和终端不自动执行。

共享组件的浮窗、长文及设置回归脚本均通过，覆盖移动、缩放、窄屏、全屏、草稿、错误和 Key 表单。Mac 默认参数及后端不变；这些浏览器检查不等于 Mac 实机回归。

## 实机与交付范围

独立 Pro 普通用户与真实受保护嵌套 Linux 已通过 10 项调用链路检查：启动、加密设置且不自动调用、长中文与段落、方向覆盖、401 脱敏且不重试、过长结果拒绝、断开请求后的实际进程回收、移除 Key 后取消、日志无原文/Key/译文、资源删除。生产 Python 的网络发送函数在验收进程内被本地桩替换，禁止实际执行 curl；不把合成译文计为外部服务可用性证明。

独立证据程序将实机执行的 6 个后端编译文件与当前安装包和本地编译产物逐字节摘要核对。实机专项没有操作 Windows 浮窗或系统文字剪贴板，前端行为由上述 19 项合成界面检查单独覆盖，两者范围不混算。

测试后的内层 VM、专属交换机、受保护登记双副本与运行目录均确认为零，应用和 SSH 进程退出。合成输入窗口的定时退出及任务回收已确认，真实输入事件仍为零；Pro 测试机保持运行等待用户手动登录，网卡断开、合成自动登录关闭。物理宿主启动时间与远端 `main` 引用保持不变。

初始化失败时保留原回执和磁盘；只有在无活动进程、VM 已关闭、实际 GUID、受保护登记、所有者和磁盘目录匹配后，才刷新诊断代码并在原盘重试。首次未取得 GUID 的失败可先生成独立关闭状态观察证明，不改写原失败回执或将其记作通过。

复核命令为 `node scripts/windows-pro-probe.ts translation-inspect`、`node scripts/windows-pro-probe.ts collect-state` 和 `node scripts/windows-pro-translation-evidence.ts`。`collect-state` 核查资源并关闭测试自动登录，保留外层测试机供手动登录；不会重启物理宿主。

未签名 NSIS 安装包已构建。审计检查 5632 个文件，165 个代码文件与暂存载荷一致，未发现本轮本机用户路径或运行私密文件。

真实 Windows 输入法、桌面文字剪贴板手势、安装版图形主入口与系统认证继续独立验收。外部翻译服务和 AI 网站由用户主动测试，本轮不访问。物理切网与休眠、实际听音、进阶功能及 Mac 实机回归仍在 [工作清单](windows-work-plan.md) 中。
