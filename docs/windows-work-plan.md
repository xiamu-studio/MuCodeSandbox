# Windows 开发工作清单

目标：Windows 采用独立 Hyper-V 后端，实现与当前 Mac Linux 模式相同的可验证防护边界；Mac 的 Lima/VZ、Swift、桌面入口和发布流程保持独立。所有账号测试留给用户，不主动访问 AI 网站。

## 第一阶段：真实虚拟机与严格网络

- [x] 独立 Windows 分支、数据目录、CLI 与默认关闭规则。
- [x] Hyper-V 已启用，重启后服务运行，系统待重启标记消失。
- [x] 验证 Hyper-V ACL 后，实机方案升级为 Private 交换机和双向 IP 全拒绝；管理使用 Hyper-V socket，避开宿主普通代理路由。
- [x] 官方组件固定摘要校验；大镜像支持分段、断点续传及最终整体 SHA-256 校验；本地回环下载测试已通过。
- [x] Canonical 基础镜像完成下载、校验和提取。
- [x] 真实 Linux 创建、启动、SSH、独立网卡/磁盘/密钥验证。
- [x] 构建空白受保护基盘，离线核查二进制、关闭规则和旧管理密钥清理。
- [x] 两个本地 HTTPS 接收端的端到端业务开关实验（首轮内核实测 8/8）。
- [x] 真实内核许可到期、旧连接与新连接阻断，禁止过期续期。
- [x] 代理/DNS 中断、内核规则/策略路由/Hyper-V ACL 篡改均触发确认停机（扩展内核矩阵 16/16，多环境改动继续复核）。
- [x] 控制进程强退后，在客体许可尚有效时宿主转发即关闭，且无人续期后许可到期；原生助手退出亦通过本机测试。
- [x] 同一运行时双环境独立代理/许可、文件、身份与故障隔离（实机矩阵 7/7）。
- [x] VM 开机前启动宿主/独立接收端观测，验证启动 IP 包被拒绝；模拟同链路/其他网段的原始 IPv4/IPv6 绕过，并以允许对照、逐包标识和零采集丢失校准（10 项实机检查）。
- [x] 隔离 Windows 评估 VM 内真实网卡启停、DNS/路由变化触发生产监测器关闭嵌套 Linux，旧流停止、新请求及重启拒绝，清理并恢复测试网络（13 项），详见 [网络变化验收](windows-network-transition-validation.md)。
- [ ] 物理网络切换和实际操作系统休眠/唤醒验证及对应逐包观测；涉及用户当前网络或会话时单独安排。

状态机单测、脚本语法检查和构建不能代替上述真实 VM 验收。完整安装包和实际运行证据须分别记录。

## 第二阶段：Windows 产品界面与日常功能

- [x] 独立 Windows 管理器和本机 API，支持新建、编辑、启动、停止、重启、状态与日志；不替换 Mac 管理器和服务。
- [x] Windows 管理界面接入上述生命周期和防护核验，未实现功能不提供可用入口。
- [x] DPAPI 当前用户加密、受限数据目录、操作系统管理的单实例锁、启动恢复和监测失败后的停机。
- [x] ConPTY 交互式 Linux 终端、dev 身份、禁止 sudo、UTF-8 中文、尺寸同步和文本粘贴；停止/核验失败撤销连接。
- [x] 终端原生组件独立子进程，正常关闭和控制进程强退后均回收工作进程及其宿主 shell。
- [x] 手动文件上传/下载、目录浏览、上传进度和取消；复用 Linux 侧路径、链接及文件版本校验。
- [x] 独立 AMD64 图形基盘与组件目录、Linux Chrome/VNC 画面、渲染器/GPU 沙箱检查、原生语言/时区和真实画面密度。
- [x] 浏览器本地 HTTPS、上传/下载、Canvas/Worker、手动中文剪贴板及上游故障后撤销画面并停机。
- [x] CLI 与管理页默认数据目录一致；兼容早期 `app/hyperv` 数据，不迁移现有 VM。
- [x] 独立普通用户桌面入口、沙箱化管理画面与内置 Node；正常关闭、渲染器崩溃的真实 VM 验证。
- [x] 在已启用 Hyper-V/OpenSSH 的机器上，通过界面从官方组件准备空白图形基盘；受限构建器、管理员缓存与摘要引用，新克隆正常出口/浏览器验收。
- [x] 首次准备的取消、未完成发布恢复与拒绝未知组件/错误清理对象；本地状态保留，普通 VM 不作为构建器保存或自动删除。
- [x] Windows 系统组件状态界面、受限 Hyper-V/OpenSSH 客户端准备操作和仅系统准备会话；后台操作与代理退出交接、已就绪机器不修改/不重启的实测。
- [x] 桌面主进程强退的包级停机验收；固定实际 Electron PID，独立 Hyper-V 检查确认 Off（约 1.7 秒）。
- [ ] 音频接入、真实输入法、翻译浮窗和桌面快捷键。
- [ ] 剪贴板图片及其他桌面文件操作。
- [x] 管理文件清理拒绝重解析点，固定目录句柄防止路径替换，普通用户清理不递归跟随目录联接。
- [ ] 受限共享、宿主桥接及其余 Windows 文件权限边界。
- [x] 可选权限分离预览：普通用户控制器、绑定进程的受限 Hyper-V 代理、管理员保护的组件/磁盘和控制器强退后的独立停机检查。
- [x] 权限代理失败/取消创建重试、丢失回执与本地清单恢复，保留已创建环境的原磁盘。
- [x] 普通用户界面确认环境名称后删除 VM、专属交换机、虚拟磁盘和管理密钥；独立检查确认实际资源消失。
- [x] 受保护登记双副本与旧格式迁移、丢失/损坏恢复、双丢失拒绝、未登记旧数据保留及新建拒绝覆盖（18 项真实嵌套 VM、95 项 Windows 自动测试），详见 [登记恢复验收](windows-ledger-recovery.md)。
- [x] 缓存空间统计、当前/登记基盘与磁盘父链/检查点引用保留、审阅计划校验及清理/导入互斥；11 项真实后端、7 项页面/API 与 113 项 Windows 自动测试，详见 [缓存回收验收](windows-cache-reclamation.md)。
- [ ] 旧管理员环境迁移、没有可信副本时的显式资源接管及完整并发/容量边界审查（创建/启动、低磁盘空间、内存压力等）。
- [ ] Hyper-V 磁盘扩容、快照、加密备份及跨架构迁移边界。
- [ ] WireGuard 与其他网络模式逐项实现和验收，未通过的模式不启用。

## 第三阶段：交付与回归

- [x] 独立 Windows NSIS 未签名测试包构建，内置 Node 固定摘要校验，不包含 VM、账户或运行数据。
- [x] 当前用户安装、同版本重复安装、显式等待卸载、用户数据保留及运行中拒绝安装/卸载的 5 项实测；安装目录与系统临时目录分属不同磁盘。
- [x] 隔离 Windows 11 IoT LTSC 评估 VM 中真实安装缺失 Hyper-V、仅重启测试 VM，以普通用户及另一管理员身份验证后端，再运行嵌套 Linux 并清理（3+5 项）；OpenSSH 在系统镜像中预装，详见 [全新 Windows 验收](windows-clean-host-validation.md)。
- [x] 缺失 OpenSSH 客户端的真实移除、断网失败关闭、微软 FoD 源实际安装及重新检测后嵌套 Linux 启动（3+5 项）；修复无效 DISM 参数及未就绪时错误完成的路径，详见 [OpenSSH 验收](windows-openssh-validation.md)。
- [ ] 第二台 Windows 11 Pro、控制面板/交互式向导和跨版本升级验证。
- [ ] Windows 实机全流程及第二环境回归。
- [ ] Mac 共享接口变化的真实回归；无 Mac 实机时不得声称已通过。
- [ ] 如需正式签名，用户提供代码签名身份后执行；测试包和正式发行分开标注。
- [ ] 完成 Windows 分支审查后再决定是否合并，开发期间不修改 `main`。

现有 GitHub 历史文档中的个人路径和出口记录属于另一个隐私清理事项；本阶段新增源文件只使用通用配置与保留测试地址，运行日志、密钥、磁盘和本机报告均不提交。
