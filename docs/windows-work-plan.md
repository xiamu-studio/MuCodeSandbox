# Windows 开发工作清单

目标：Windows 采用独立 Hyper-V 后端，实现与当前 Mac Linux 模式相同的可验证防护边界；Mac 的 Lima/VZ、Swift、桌面入口和发布流程保持独立。所有账号测试留给用户，不主动访问 AI 网站。

## 第一阶段：真实虚拟机与严格网络

- [x] 独立 Windows 分支、数据目录、CLI 与默认关闭规则。
- [x] Hyper-V 已启用，重启后服务运行，系统待重启标记消失。
- [x] 验证 Hyper-V ACL 后，实机方案升级为 Private 交换机和双向 IP 全拒绝；管理使用 Hyper-V socket，避开宿主普通代理路由。
- [x] 官方组件固定摘要校验；大镜像支持分段、断点续传及最终整体 SHA-256 校验；本地回环下载测试已通过。
- [x] Canonical 基础镜像完成下载、校验和提取。
- [x] 真实 Linux 创建、启动、SSH、独立网卡/磁盘/密钥验证。
- [x] 构建空白受保护基盘，离线核查二进制、关闭规则和旧管理密钥清理。
- [x] 两个本地 HTTPS 接收端的端到端业务开关实验（首轮内核实测 8/8）。
- [x] 真实内核许可到期、旧连接与新连接阻断，禁止过期续期。
- [x] 代理/DNS 中断、内核规则/策略路由/Hyper-V ACL 篡改均触发确认停机（扩展内核矩阵 16/16，多环境改动继续复核）。
- [x] 控制进程强退后，在客体许可尚有效时宿主转发即关闭，且无人续期后许可到期；原生助手退出亦通过本机测试。
- [x] 同一运行时双环境独立代理/许可、文件、身份与故障隔离（实机矩阵 7/7）。
- [ ] 启动首包与禁止宿主/局域网旁路的独立包级证据。
- [ ] 实际网络切换和休眠/唤醒验证；涉及用户当前网络或会话时单独安排。

状态机单测、脚本语法检查和构建不能代替上述真实 VM 验收。完整安装包和实际运行证据须分别记录。

## 第二阶段：Windows 产品界面与日常功能

- [x] 独立 Windows 管理器和本机 API，支持新建、编辑、启动、停止、重启、状态与日志；不替换 Mac 管理器和服务。
- [x] Windows 管理界面接入上述生命周期和防护核验，未实现功能不提供可用入口。
- [x] DPAPI 当前用户加密、受限数据目录、操作系统管理的单实例锁、启动恢复和监测失败后的停机。
- [x] ConPTY 交互式 Linux 终端、dev 身份、禁止 sudo、UTF-8 中文、尺寸同步和文本粘贴；停止/核验失败撤销连接。
- [x] 终端原生组件独立子进程，正常关闭和控制进程强退后均回收工作进程及其宿主 shell。
- [x] 手动文件上传/下载、目录浏览、上传进度和取消；复用 Linux 侧路径、链接及文件版本校验。
- [x] 独立 AMD64 图形基盘与组件目录、Linux Chrome/VNC 画面、渲染器/GPU 沙箱检查、原生语言/时区和真实画面密度。
- [x] 浏览器本地 HTTPS、上传/下载、Canvas/Worker、手动中文剪贴板及上游故障后撤销画面并停机。
- [x] CLI 与管理页默认数据目录一致；兼容早期 `app/hyperv` 数据，不迁移现有 VM。
- [ ] 独立桌面客户端、音频接入、真实输入法、翻译浮窗和桌面快捷键。
- [ ] 剪贴板图片及其他桌面文件操作。
- [x] 管理文件清理拒绝重解析点，固定目录句柄防止路径替换，普通用户清理不递归跟随目录联接。
- [ ] 受限共享、宿主桥接及其余 Windows 文件权限边界。
- [x] 可选权限分离预览：普通用户控制器、绑定进程的受限 Hyper-V 代理、管理员保护的组件/磁盘和控制器强退后的独立停机检查。
- [x] 权限代理失败/取消创建重试、丢失回执与本地清单恢复，保留已创建环境的原磁盘。
- [x] 普通用户界面确认环境名称后删除 VM、专属交换机、虚拟磁盘和管理密钥；独立检查确认实际资源消失。
- [ ] 旧管理员环境迁移、登记表丢失后的资源接管、共享基盘缓存回收及并发/容量边界完整审查；独立 Windows 桌面入口。
- [ ] Hyper-V 磁盘扩容、快照、加密备份及跨架构迁移边界。
- [ ] WireGuard 与其他网络模式逐项实现和验收，未通过的模式不启用。
