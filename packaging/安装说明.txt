MuCodeSandbox — Mac 测试安装包

安装：打开 DMG，将 MuCodeSandbox 拖到“应用程序”，然后从“应用程序”启动。

机型：仅 Apple Silicon（M 系列）Mac，不支持 Intel Mac。
系统：构建目标 macOS 13及以上；当前只在开发机 macOS 26.3.1 上验证。尚未在第二台 Mac 或 macOS 13/14/15 上实机验收，不能把构建目标当成已验证支持列表。

首次使用：
1. 应用第一次启动是空白工作区，不含任何人的虚拟机或登录资料。
2. 在“系统设置”中安装 Lima 运行组件，首次使用需要联网下载组件与 Linux 镜像。
3. 新建 Linux 环境，填写自己的代理或隧道、语言及时区。按实际需要设置固定出口核验。
4. 等候启动与防护核验通过，再使用本地首页检查画面、出口和文件工具。
5. 翻译需要自己配置 API Key，只有手动点击翻译才发请求。

每台 Mac 保存自己的环境和 Key。安装包没有附带 VPS、代理密码、浏览器登录、项目文件、翻译 Key 或 VM 磁盘。不要为了安装应用而复制他人的隐藏数据目录。

签名状态：本包使用本地临时签名，未完成 Apple Developer ID 签名及公证。另一台 Mac 首次打开可能被系统拦截，打包为 DMG 不会改变这一状态。请核对来源与 SHA-256；若系统或单位策略不允许运行，应按其管理流程处理。
正式分发说明：https://developer.apple.com/developer-id/
不要关闭系统整体安全防护来安装此测试包。

普通退出保留已保存资料；重建或删除环境会清除对应 VM 的磁盘。退出应用前自行保存未发送的文字或翻译草稿。

本测试包未验证第三方真实账号、所有机型、所有系统版本或长期网络故障场景；虚拟机与不同 IP 不保证账号不可关联。
